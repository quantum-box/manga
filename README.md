# AI漫画制作プロジェクト

AIを使って、企画から作画、組版、修正、書き出しまで進めるための実験プロジェクト。

最初の試作: [柴犬ポチと魔王の「おて」](examples/pochis-handshake/README.md)

カラー縦読み版: [Webtoon試作](examples/pochis-handshake/webtoon/README.md)

再調査と作り直し案: [Webtoon再調査](docs/webtoon-research.md)

## 最初に検証すること

仮の題材は**日本語・白黒・1ページの短編漫画**。ジャンルや掲載形式が決まったら変更する。

1. 同じ登場人物を複数コマで識別できるか
2. コマごとの構図と感情が脚本に沿うか
3. 日本語のセリフを読みやすく配置でき、後から直せるか
4. 気に入らないコマだけ再生成できるか
5. 1ページを作る時間・生成回数・費用を記録できるか

## 制作フローの仮説

`あらすじ → キャラクター設定・参照画像 → ページ/コマ脚本 → コマ別作画 → ページ組版 → 吹き出し・文字 → 人の確認 → 書き出し`

脚本、コマ割り、参照画像、生成条件、セリフの位置を別々に保存する。画像生成モデルには原則としてセリフを描かせず、文字は組版工程で重ねる。これなら個々のコマと誤字を修正しやすい。これは採用済みの実装ではなく、最初の実験仮説。

## 参考事例

| 事例 | 参考になる点 | 確認したい限界 |
| --- | --- | --- |
| [MangaFlow (2026)](https://arxiv.org/abs/2605.28173) | 計画、参照、レイアウト、作画、文字を分離し、長編向けの記憶を持つ | 実装の公開状況、再現性、必要な計算資源 |
| [MangaDiffusion (2024)](https://arxiv.org/abs/2412.19303) | 複数コマのレイアウトとコマ間の整合性を研究対象にする | 実運用の編集フローへの適合 |
| [StoryDiffusion](https://storydiffusion.github.io/) | 連続画像で同じ人物を保つための生成手法 | 漫画の組版・文字編集は別工程が必要 |
| [AI Comic Factory](https://github.com/jbilcke-hf/ai-comic-factory) | 物語からコマ画像と吹き出しまでつなぐ公開例 | リポジトリはアーカイブ済み。運用前に依存先を確認 |
| [manga-studio](https://github.com/ahmet360/manga-studio) | ComfyUIでコマごとに描き、セリフを後から合成する実装例 | モデル・フォントの権利、品質、保守状況 |
| [ComfyUI-Manga-Autopilot](https://github.com/Kataage/ComfyUI-Manga-Autopilot) | コマ編集、テンプレート、作画ワークフローの管理 | 導入コストと必要な拡張機能 |

## 生成方式の比較候補

最初の試作は、このチャットの画像生成機能で行う。キャラクター案・参照画像・各コマを生成して品質と修正のしやすさを確認する段階では、外部API接続や画像生成コードは不要。生成した画像、使った指示、採用・不採用の理由を残す。

| 候補 | まず比べること |
| --- | --- |
| このチャットの画像生成機能 | 1ページを実際に作り、キャラの一貫性とコマごとの修正を確かめる |
| [Geminiの画像生成・編集API](https://ai.google.dev/gemini-api/docs/image-generation) | 複数のキャラ参照画像で異なる構図を作った際の同一性、コマの修正しやすさ、費用 |
| [OpenAI Images API](https://developers.openai.com/api/reference/resources/images) | 同じ脚本・参照画像での品質、編集、費用 |
| [ComfyUI](https://docs.comfy.org/) | ローカル実行時の制御性、導入と保守の手間、モデルごとの利用条件 |

反復制作やアプリへの組み込みが必要になった段階で、APIやローカル実行を比較する。ページ構成と文字入れは生成方式に依存させない。形式はページ・コマ・登場人物・セリフ・読順・画像参照・生成条件を持つ構造化データとし、組版の書き出し候補はSVG。

## 最初の実験

- オリジナルの短い脚本と2人以下の登場人物を用意する。
- キャラクターシートを作り、同じキャラを異なる角度・表情・距離で4〜6コマ描く。
- コマをページに配置し、日本語の吹き出しを画像とは別に載せる。
- 人が「同一人物と分かるか」「読む順序が自然か」「セリフが読めるか」を確認する。
- 失敗したコマのみ直し、生成回数・所要時間・費用を記録する。

## 未決定
