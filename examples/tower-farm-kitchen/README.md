# 塔の農夫は、英雄を食わせる

[話一覧を開く](chapters.html)。200話以上の指定に対して、初期ロードマップは240話。第1〜10話の脚本・絵コンテを制作し、現在10話が作画とスマホ確認まで完了。

塔の三階で行き場を失った農夫が、帰還食堂の料理人と畑・作付け・水・献立・補給を組み直す。農業と設備には材料、時間、費用、失敗の条件を持たせる。
