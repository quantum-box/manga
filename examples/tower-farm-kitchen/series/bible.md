## 一文の企画

塔の三階で行き場を失った農夫が、潰れかけの帰還食堂を守るため、農地・水・作付け・料理・補給を組み直し、上層へ挑む冒険者たちに「明日も食べられる」を届ける。

塔を中心にする理由は、階層ごとに気候と素材が違い、上へ進むほど輸送と補給が難しくなるから。新しい階の攻略が農業と厨房の新しい課題を生む。職業・技能・ギルド・生産依頼の楽しさを加え、MMORPG的な読み味を持たせる。住民が暮らす実在の世界として描く。

## 読者への約束

1. うまくいかない畑や店の原因が、観察と作業で分かる。「見えていたのに気付かなかった」が逆転の快感になる。
2. 泥と汗が、湯気の上がる一皿になる。作ったものを誰かが食べるまでをつなぐ。
3. 冒険者の勝利に主人公の仕事が効く。遠征の継続、欠品の解消、帰還後の安心が、成果として見える。
4. 魔法の便利さと設備の面白さが両立する。安く、壊れにくく、他人にも使える工夫が広がる。
5. 畑、店、仲間、補給先が増えていく。前の改善を失敗前の状態へ戻して話数を稼がない。

トーンは、手仕事の手応え、温かい食事、商売の逆転、王道の冒険。農業の検証を楽しめる密度を保ち、読み手が今応援している人物と目的を毎場面で分かるようにする。

## 主人公と無双の形

主人公案は浅井耕介、28歳。小規模野菜農家で七年間、栽培と出荷を担当してきた。実家の食堂へ規格外野菜を納めた経験があり、厨房が欲しい大きさ・量・時間を理解している。料理の専門家は現地の相棒に担ってもらう。

召喚時に授かった職業は〈耕作者〉。戦闘技能は乏しい。強みは、土を見て水を疑い、比較区を残し、成功を記録して次の作業へ渡せること。未知の作物や魔力障害では、現地の農家や技師から教わる。

成長の道筋は「一畝を救う → 小さな店を続ける → 自分も塔を登って種と素材を獲得する → 栽培と料理で遠征を強くする → 上層を攻略しながら複数拠点を育てる」。話数と転換は[ロードマップ](roadmap.md)へ記録する。最終的には耕介一人が働かなくても回る畑と厨房を作り、本人は仲間と頂層へ進む。農地と食堂の連合が塔の居住区を支える。

無双の見せ場は、最高級食材を出すことだけではない。他店が欠品する日に温かい定食を出す、輸送が止まっても備蓄で遠征をつなぐ、同じ予算で安全な食事を多く届ける。味への驚き、行列、次の予約、攻略隊からの指名が直接の報酬になる。

2026-10-08のユーザー指定：今後は、読んでいて高揚する無双展開を強める。第11話以降は、原因を調べて堅実に改善する過程だけで終わらせず、圧倒的な成果、周囲の驚き、主人公たちの利益と地位の上昇まで描く。成功直後に次の損失で報酬を消さず、勝った喜びを味わう場面を確保する。[続話の無双と報酬](payoffs.md)を詳細構成の基準にする。

同日の追加指定「あと塔も登らないと」：塔を登るのは攻略者だけでなくコウ本人。第16〜20話に最初の四階遠征と未攻略分岐の突破を置き、五階、七階、十二階、さらに上層へ進む。農業・料理と登塔を交互に独立した話として挟むのではなく、遠征の報酬が次の栽培を強くし、その成果が次の攻略を可能にする循環にする。

## 最初に読者へ見せたい場面の種

食堂の相棒は、萎れた葉を見て自分の世話が足りなかったと思っている。肥料も水も追加したのに、畑はさらに悪くなった。耕介は湿った土を持ち上げ、根の状態と畝の低い側を確かめる。

「もう肥料は足さなくていい。先に、水の出口を見よう」

食堂が閉まる前に何かしたいという焦りから、主人公は大きな復旧を約束しそうになる。しかし枯れた株と、まだ救える株を分け、店に出す分も限る。排水を直した直後に全株が元通りになる演出は避け、日を置いた新しい根と葉、残せなかった区画を両方見せる。

その後の料理は、救えた既存の作物と買い入れた穀物・肉で作る。播いたばかりの種から当日の料理を出さない。「今日は出せる。でも来週は？」という店の問題が、作付けの必要へつながる。

これは各話の脚本ではなく、作品固有の面白さを確認する場面案。

## 事件を生む仕組み

| 仕事から生まれる課題 | 解決が作る次の変化 |
| --- | --- |
| 排水・日照・塩類・病害で収量が落ちる | 比較試験と設備改修が必要になり、土地・水の利用で隣人と調整する |
| 人気が出て収穫より注文が増える | 作付け、仕入れ、雇用、品切れの説明が必要になる |
| 新しい階への納品依頼が来る | 保存、重量、燃料、運送、遠征日程を組み直す |
| 他店や農家が技術を使い始める | 共通の道具、種の供給、保守、品質の約束が必要になる |
| 塔の環境制御が不調になる | 畑と町の双方が影響を受け、攻略と生活基盤の問題が合流する |

作品を貫く問いの候補は「強い人が勝てる場所を、普通の人が暮らせる場所にできるか」。登場人物は食事を楽しみ、儲け、故郷を守り、攻略の夢を追う。全員に同じ思想を語らせない。
