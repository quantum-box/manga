# 世界 — 剣と魔法と補給の塔

すべて企画段階の仮設定。現実の農学の根拠は[sources.md](sources.md)、設備と数値の扱いは[agriculture.md](agriculture.md)を参照する。

## 塔と暮らし

巨大な塔の外には王国、麦畑、牧場、街道がある。剣士、魔法使い、治療師が塔へ挑み、鉱物・魔石・食用として認められた素材を持ち帰る。農業と料理は既に職業として成り立っており、主人公は現地の知識へ計測・工程管理を接続する。

塔には戦闘区と維持管理された居住区がある。攻略して拠点を認定した階だけに共同農地、倉庫、厨房を置ける。床、壁、水路は実際の構造物で、好きな位置へ穴を開けると別区画に影響する。居住区の外は冒険者の護衛が必要。

三階〈樹光庭〉が開始地点。天井の光脈、灌漑水路、外へ排水する共用路がある。光には明暗の周期があり、作物の生育条件を決める。塔内の種苗はこの環境へ適応している。夜も光らせ続ければすべての作物がよく育つ、という設定にはしない。

塔へ入る認証門には荷の重量・体積に応じた通行料と便数制限がある。塔外の食料を買うことは可能だが、重い水、生野菜、嵩張る燃料は上層ほど割高になる。どこからでも無制限に届く倉庫はない。三階での現地生産は鮮度と補充速度で価値を持つ。

## 職業と記録のシステム

| 仕組み | できること | 制約と物語への影響 |
| --- | --- | --- |
| 職業認定 | 修練した仕事に技能を付ける。剣士、調理師、耕作者など | 他職の技能も学べるが、時間、師匠、道具が必要。転職で経験や身体が消えない |
| 技能成長 | 仕事の再現性、難しい判断、工程の改善を補助する | 同じ穴を掘って埋めるだけの作業は成長が鈍る。報酬判定だけで社会を支配しない |
| 作業記録 | 本人が測った値、量、日付、区画を記録し比較する | 未測定の値は空欄。未知の病原体や収穫日を言い当てない。測定方法が違う値は別系列 |
| 魔導計測 | 道具と標準試料を使って温度、圧力、導電性などを見る | 消耗・校正・範囲・誤差がある。標準試料がなくなれば精度が落ちる |
| 食事の技能効果 | 相性のよい料理が、条件付きで疲労からの回復や集中を補助する | 質量と栄養は必要。重傷や病気には治療が要る。同じ料理の重ね食いで際限なく強くならない |

〈作業記録〉は地味な既存技能。耕介の特別さは技能の存在より、区画ごとの比較と帳簿を習慣にしていることに置く。最初は天秤、容器、目盛り、紙の記録でも成果を出せる。専門の測定器は技師の協力で入手・製作する。

料理の追加効果は創作上の魔法ルールとして明示する。現実の料理が即座に能力値や病気を改善するという説明にはしない。最初の料理の勝利は、おいしさ、食べやすさ、満腹、継続供給で成立させる。

## 魔法の資源収支

魔法は物を移動し、熱や光を与え、反応や作業を補助する。物質を何もないところから無制限に生み出せない。魔力は疲労や魔石の消耗として支払う。作者は変換効率を記録し、必要なら作中の単位と現実の比較単位を別に管理する。

| 技術 | 入力 → 効果 | 限界・失敗・対抗手段 |
| --- | --- | --- |
| 水術 | 水源の水＋魔力 → 揚水・配水 | 水源が枯れれば止まる。塩を含む水を動かしても塩は残る。流量と揚程で消耗が増える |
| 土術 | 既存の土＋仕事量に応じた魔力 → 掘削・成形 | 根を切る、濡れた土を締める、共用構造を壊す危険。腐植や養分の量は増えない |
| 光術 | 魔力 → 作物に使える光 | 広い農地を長く照らすと高コスト。光の種類、強さ、時間を合わせる必要がある |
| 冷却術 | 魔力＋放熱先 → 保冷・温度調整 | 冷やした分の熱を外へ逃がす。断熱不良、扉の開閉、放熱口の詰まりが消耗を増やす |
| 生育祝福 | 種・光・水・養分＋魔力 → 条件がそろった一部の生育を促す | 飢えた土では消耗が大きい。枯死した根は復活しない。食用の品質と次の種は別に確かめる |

生育祝福は既に使われている。高価な薬草、王侯向けの食材、苗の救済では採算が合う。安い定食へ毎日使うと利益が消える。主人公はそれを否定せず、適した工程に限って使う。

## 普及の理由と障壁

街には陶器、木桶、金属管、鍛冶、ガラス加工、巻き上げ機、風車がある。接合の精度と価格にはばらつきがある。初期の設備は既存の素材で作り、交換部品も用意する。樹脂の点滴チューブ、電子センサー、冷媒装置を当然の市販品として出さない。

塔外の農家には雨・季節・土地に合わせた技術がある。塔内では荷の制限、光脈の変動、少ない分析設備、農地の賃貸期間が投資を難しくしてきた。誰も重力給水を知らない世界ではなく、耕介たちが三階の制約に合わせて小さく作り直す。

種苗商は良い苗と種を売り、組合は水と共同施設を管理する。魔石商は燃料と保守を供給する。設備改良は彼らの利益を消すだけではなく、安い部品、定期保守、新しい需要を生む。協力する店と、既得契約を守りたい店の両方がある。

## 勢力と対立

| 集団 | 求めるもの・持つ資源 | 主人公と衝突する点／協力する点 |
| --- | --- | --- |
| 三階の居住者組合 | 安全な排水、水配分、暮らせる家賃 | 勝手な掘削や水の独占は止める。漏水修理と維持費の分担には協力する |
| 攻略ギルド補給部 | 欠品のない食料、一定の品質、輸送枠 | 個人店へ大量注文を任せるには証拠が必要。実績で契約を広げられる |
| 穀物・塩・魔石の商人 | 安定した販路、仕入れの回収 | 値下げには限界がある。発注の平準化や共同便が双方の利益になる |
| 農家と料理人の組合 | 種、技能、労働、評判 | 技術だけ持ち去られることを警戒。対価、共同試験、再現可能な手順で信頼を得る |
| 前線の攻略者 | 新しい階への到達、生還、報酬 | 重い食料を持ちたくない。味、重量、日持ち、休息のバランスで注文が変わる |

塔の環境制御の不調を長期の問いの候補にする。作者側の真相は[ロードマップ](roadmap.md)に配置済みで、導入では人物も読者も知らない。農業の失敗を毎回、隠された魔法や陰謀のせいにしない。現実的な原因が読者の観察で追える事件を主軸にする。
