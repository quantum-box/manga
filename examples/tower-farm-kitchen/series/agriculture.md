# 農業・設備・食堂 — 技術設定のたたき台

物語の手仕事に使う設定資料。現実の根拠は[sources.md](sources.md)へつなぐ。魔法、在来作物、塔の環境、価格、下記の栽培日数・収量は創作上の仮定。現実の作物へ共通の推奨値として使わない。

## 1. 症状を見て、原因を切り分ける

農業の場面は「症状 → 仮説 → 確認 → 小さく試す → 待つ → 結果 → 次の判断」でつなぐ。システムの警告だけで原因と処方が同時に出ない。新しい技術の説明は、失敗をどう避けるか、今の注文へ何が変わるかとセットにする。

| 同じように見える症状 | 疑うこと | 作中で見せる確認・判断 |
| --- | --- | --- |
| 土が湿っているのに萎れる | 過湿、根の病害、塩類など | 根と根域の土を調べ、排水路、水源、塩類の測定を別に見る。見た目だけで病名を断定しない |
| 葉が黄色い | 養分不足、根の傷み、pHなど | 新葉／古葉、区画の分布、根、水、分析結果を照合。即座に窒素を追加しない |
| 同じ畝の端だけ小さい | 配水の偏り、詰まり、陰、地形 | 同じ時間に各出口の水を容器で受け、量を比べる。光と低い場所も記録する |
| 葉は茂るが収穫部が育たない | 品種、光、過剰な施肥、着果条件など | 収穫部と時期に合わせて調べる。魔力の強さだけで収穫量を説明しない |
| 品質が日によって違う | 成熟度、収穫時刻、保存、品種など | 区画と収穫日を厨房の評価へ結び付ける。味の違いを生産側へ戻す |

導入候補の畑は、排水の悪化で根域が長く湿った区画。主要因は観察と比較で確かめる。水を足すのを止め、管理者と出口を確認し、まだ回復可能な部分から対処する。すでに枯死した根と株は回復させない。全滅した区画は植え直しに時間がかかる。

一度の比較で普遍的な正解にはしない。比較区、作物、播種日、場所、使った水、施肥量を残す。できる範囲で複数区を使い、場所の差と処理の差を分ける。量を変える時は一度に多くの条件を変えず、何が効いたかを追えるようにする。

土の分析は、正常な場所と異常な場所を混ぜず、深さと採り方をそろえる。pH、塩類、養分、有機物、物理的な状態は別の指標。「土の品質92点」という一つの値にまとめない。水のEC、土の抽出液のEC、培養液のECは測定法が違い、そのまま比較しない。[土の分析](https://extension.umn.edu/agriculture/specialty-crops/interpreting-soil-tests-for-fruit-and-vegetable-crops)、[灌漑水の分析](https://extension.psu.edu/interpreting-irrigation-water-tests)。

## 2. 水、光、設備を具体的に作る

### 水は量と行き先を描く

根には水と空気の両方が必要。排水は、出口の高さ、受け入れ先、地下の状態までつながって初めて機能する。畝を高くしただけで地下水や排水先の問題が消えたことにしない。耕す時は湿り過ぎた土を踏み固めない。根のある畝と人の通路を分ける。[排水](https://extension.umn.edu/natural-resources/conservation/agricultural-soil-and-water/how-agricultural-drainage-works)、[土の締まり](https://extension.umn.edu/natural-resources/conservation/agricultural-soil-and-water/soil-compaction)。

水収支の作者用の式は `貯留量の変化 = 降雨等 + 灌水 + 毛管上昇 - 蒸発散 - 表面流出 - 下方への排水`。各項の単位をそろえる。塔の霧や凝縮水も入力量として記録する。地表が乾いていても、根域が湿っていることがあるため、表面だけを見て灌水しない。

以下は、水量と設備サイズの関係を見せるための**創作上の計算例**。灌水量の推奨ではない。

| 条件・計算 | 結果 |
| --- | --- |
| 作付け面積48 m²、正味の補給量を仮に2 mmとする | 48 × 2 = 96 L |
| 降雨・毛管上昇の寄与をゼロ、給水の有効率を仮に75%とする | 水源側で96 ÷ 0.75 = 128 L必要 |
| 160 Lのタンクを用意する | 水だけで最大約160 kg。架台と設置床の負荷を確認する |
| タンク水面と出口の高低差が2 m | 静水圧は約19.6 kPa = 0.196 bar。流れる時は管の損失でさらに低下する |

`1 mm × 1 m² = 1 L`の換算は[FAO](https://www.fao.org/4/r4082e/r4082e05.htm)に基づく。75%と2 mmは仮定。飽和している導入の畑へこの量を毎日足す設定ではない。必要量は作物の段階、根域、水分、光、温湿度を見て変える。

### 初期の設備：高架桶と区画ごとの給水

水源 → 汲み上げ → 沈殿桶 → 交換できるろ材・網 → 高架桶 → 元栓 → 区画の配水管 → 開閉できる出口、という順にする。清掃口、末端の排出口、漏れを確認する目印を設ける。飲用・厨房用の水系統は別に管理する。

現地で作れる木桶、陶管、短い金属継手から始める。最初は出口を一つずつ開け、容器で受けた量を比べて給水する。高架桶を置くだけで全出口が均一になるとは扱わない。水位の低下、配管長、太さ、出口の加工差で量が変わる。

後の点滴灌漑は、低圧で動く出口をイリスが試作し、手前・中央・末端の吐出量を調整してから使う。市販の高圧向け機器を低い桶へつないで成功させない。細い出口は詰まるため、ろ過、洗浄、交換が装置の仕事に含まれる。[点滴灌漑の設備](https://extension.psu.edu/drip-irrigation-for-vegetable-production)。

水術は桶へ上げる時に使い、配水の間ずっと魔法使いを拘束しない。魔法が止まっても桶の残量で仕事を続けられる。主人公の利点は魔力無限ではなく、働く時間と消耗を減らす設計に置く。

### 光と保冷

光脈の明るさには場所の差と時間の差がある。最初は影の位置、明暗の時刻、育ちを記録する。葉菜と果菜を同じ光条件で同じように育てない。照明を増やす場合は、対象、光の種類と量、点灯時間、熱、魔石代を試験する。数値設定は植物と計測器を決めてから追加する。

冷却箱は、断熱、隙間、扉、棚、放熱口を描く。熱を逃がす面を塞ぐと性能が落ちる。野菜を大量に詰めれば冷えるまで時間がかかる。魔石の強さだけで解決せず、入れる前の熱と開閉回数を減らす。初期は生ものの在庫を小さくし、冷却を一部の食材に限る。

## 3. 種から収穫まで、時間と生態を残す

| 工程 | 描く細部 | 失敗や次の課題 |
| --- | --- | --- |
| 作物・品種を選ぶ | 現地の気候、光、店の需要、種の入手先、比較用の少量 | 現代の作物名だけで特性を決めない。現地の品種にまず学ぶ |
| 発芽を確かめる | 同じ条件で播いた数と発芽数を記録、種のロットを分ける | 発芽率だけで収穫量を保証しない。古い種と新しい種を混ぜない |
| 育苗・定植 | 根、苗齢、用土、水、移植の傷み、植え付け深さ | 小さい苗が翌日に成株になる描写を避ける。移植に向かない作物は直播する |
| 間引き・除草・管理 | 株間、収穫したい大きさ、雑草との競合、通風、手作業の時間 | 密植で重量だけ増やしても、店の使える品質になるとは限らない |
| 収穫・次作 | 収穫基準、選別、重量、残る株、次の播種、輪作の余地 | 収穫物をすべて売ると、採種や苗・次作の余地がなくなる |

在来葉菜〈庭葉〉を最初の候補とする。地球のレタス等の性質をそのまま保証せず、バルトの経験と試験で特性を確かめる。短い周期の作物から店へ供給し、長くかかる穀物や果菜は時間経過と別区画で育てる。店舗の主食と肉は当初仕入れる。

堆肥は、投入原料、含水、空気、温度の推移、切り返し、熟成を記録する別工程。畑へ入れる量は分析と目的で決める。堆肥の山を積んだ翌日に完成させない。肥料が多すぎる時は養分の偏りや塩類が問題になり得る。[堆肥を入れ過ぎた土](https://extension.umn.edu/agriculture/specialty-crops/too-much-compost-and-manure)。

魔物の残渣は、種類、成分、毒性、魔力残留、処理、汚染を確認する研究候補に留める。導入の畑へ万能肥料として大量投入しない。食用として認められた素材と、それ以外を分ける。動物由来の未処理資材を使う場合の衛生上の課題は現実にもある。[動物由来資材](https://blog-fruit-vegetable-ipm.extension.umn.edu/2024/04/can-i-safely-use-animal-based-compost.html)。

病害虫は、巡回 → 分布と症状の記録 → 同定の相談 → 被害と介入の判断 → 手段の選択 → 効果の確認、の順で扱う。病害、昆虫、過湿、塩類を混同しない。防虫網のような道具にも、通風、作業性、受粉が必要な作物との相性がある。防除と受粉、保存・発酵の具体条件は、その作物・技術を登場させる際に個別の一次資料を追加する。

土術で耕す、生育祝福で一部を助ける、魔物素材を使う場合も、養分の持ち出し、土の締まり、作物の病気、品質、次の種を記録する。魔法の使用後に現実的な工程がすべて不要になる設定にはしない。

## 4. 作付けを食数へ変換する

敷地全体は仮に240 m²。導入で立て直す作付けは48 m²。残りは建物、通路、排水、資材、育苗、未復旧区画に使い、全面を収穫面積として計算しない。

以下は〈庭葉〉の試験結果が出る前の作者用計算。28日、0.8 kg/m²、20%の損失はすべて**創作上の仮定**。品種・季節・実測により修正する。作付けを小分けにして収穫をつなぐ考え方は[作付け計画](https://extension.umn.edu/agriculture/specialty-crops/vegetable-farming/crop-and-field-planning-tools-for-vegetable-farmers)を参照した。

| 計画の仮定 | 計算 |
| --- | --- |
| 48 m²を4 m²ずつ12区へ分け、7日ごとに3区を播く | 12 m² × 4週 = 48 m²。播種と収穫の計画をずらす |
| 栽培28日、面積当たり収穫0.8 kg、選別等の損失20% | 1週の使用可能量は12 × 0.8 × 0.8 = 7.68 kg |
| 1食の葉菜を、調理前の使用可能量で60 gとする | 7.68 ÷ 7 ÷ 0.06 ≈ 18.3食／日 |
| 店の約束をまず16食／日とする | 16 × 7 × 0.06 = 6.72 kg／週。計画との差は0.96 kg／週 |
| 栽培が35日へ延びた場合、同じ面積と収量を仮定する | 平均48 × 0.8 × 0.8 ÷ 35 ÷ 0.06 ≈ 14.6食／日へ低下 |

0.96 kgは余裕が小さい。生育の遅れや欠株に備え、現地農家からの仕入れ、献立の変更、予約の上限を用意する。28日の連作を年間維持できるという保証ではない。植え直し、休閑、土づくり、輪作、季節変動が入ると供給は変わる。

立ち上がりの最初の28日は、自分たちが播いた作物の新規収穫がない。救えた既存の成株と仕入れでつなぐ。畑の復旧、播種、初収穫、継続供給が成立する時点を別に描く。

この規模では町全体を養わない。16食が売れ、需要が増えた時は、畑の拡張、労働、種苗、用水、仕入れ、配送を一緒に増やす。特別な作物を一株収穫しただけで毎日百人に食べさせない。

作者用の区画台帳は、`区画ID／作物・品種／種ロット／播種・定植日／面積／水・施肥／症状／作業時間／収穫総量／使用可能量／厨房の評価／次作`を持つ。登場する台帳は実際に判断に使う数行を見せる。

## 5. 一皿、店、遠征へつなぐ

### 最初の献立と厨房

最初は定食と汁物に絞る。穀物と認められた食用肉を仕入れ、畑の葉菜と香味を使う。大きさが不揃いでも品質を満たす野菜を、切り方を合わせて利用する。傷み、汚染、食用適性は別に判断する。

コウは店が必要とする重量と収穫時刻を組み、エルナは洗浄、仕込み、切り方、火入れ、提供を担う。畑から持ち込む土、厨房の生材料、完成した料理の動線を作画へ残す。食材が届いても、鍋、火口、洗い場、器、人手が足りなければ出せない。

一日の仕事として、早朝の収穫・選別 → 引き渡し → 仕込み → 営業 → 片付け → 翌日の仕入れと畑の確認を描く。同じ二人が一日中休みなく働けば無制限に店を増やせる設定にしない。人を雇う時は、農作業と厨房のピークが重なる問題から始める。

### 定食の仮収支

価格は架空の銅貨換算。自家栽培した野菜も種、資材、農地、作業に費用がかかる。以下は売れた一食当たりの仮計算で、実際の賃金・仕入れ条件を描く際に調整する。

| 項目 | 銅貨換算／食 |
| --- | ---: |
| 販売価格 | 6.0 |
| 買い入れる穀物・肉 | 2.1 |
| 自家野菜の種・資材等 | 0.5 |
| 燃料・水・魔石 | 0.4 |
| 消耗品・ロス・販売に伴う費用 | 0.4 |
| 差引後、賃金と家賃等を払う原資 | 2.6 |

16食なら原資は41.6銅貨／日。そこから農業・厨房・配膳の賃金、家賃、固定の設備費、修繕、借入返済を払う。41.6を純利益と呼ばない。損益分岐は `日割りの固定負担 ÷ 2.6`。仮に36なら約13.85食、整数で14食が必要。固定負担には主人公たちの労働対価も含める。

値下げ、注文の増加、大きな設備購入を決める場面で使う数字。高品質にするため魔石を余計に使えば、味が良くても採算が崩れる。補給担当は単発の最高品質より、契約した量と日時を守れるかも見る。

### 遠征用の料理と技術の発展

| 発展する仕事 | 解く具体的な問題 | 増える責任・制約 |
| --- | --- | --- |
| 排水と区画給水 | 生育のばらつき、人が水を運ぶ時間 | 共用路、清掃、壊れた時の対応 |
| 分割播種と種苗 | 全量が同時に採れる、苗が欠ける | 種の確保、場所、日付、現地農家との連携 |
| 厨房と保冷 | 注文はあるが作れない、収穫後の品質が落ちる | 断熱、放熱、洗浄、人手、魔石代 |
| 遠征向け保存食 | 重量、体積、持ち歩く期間、必要な水 | 個別の保存法の検証、包装、燃料、運送 |
| 複数拠点の供給 | 同じ技能が別の階では通用しない | 気候、素材、保守担当、輸送便、代替調達 |

保存食は、温かい食事と同じ材料をそのまま袋へ入れて終わりにしない。乾燥で水分を減らすと重量は軽くなるが、調理に水や燃料が必要な献立もある。発酵や保存の具体条件は技術選定後に調査する。物語では、誰がどこでどう食べるかから献立を選ぶ。

農業知識のご褒美は、結果が分かる絵に置く。均一に育った列、毎週埋まる収穫箱、修理できた給水管、最後の客へ出せた定食、軽くなった遠征荷。詳細な帳簿は世界を支える裏側に残し、会話のたびに講義を挟まない。
