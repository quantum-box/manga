# 続話の無双と報酬

2026-10-08のユーザー指定「今後ドーパミンが出るような無双展開ほしい」「あと塔も登らないと」を、第11話以降の構成に適用する。ここでいう快感は、予想を超える成果、その場にいる人の驚き、主人公たちが手にする報酬として設計する。読者の生理的反応を保証する意味ではない。以下は未制作の続話構成であり、公開済みの事実ではない。

## 読ませる流れ

軽視や難題で期待を作る → コウが勝ち筋を見つける → 成果を大きく披露する → 相手と観客が驚く → 金・指名・契約・設備を得る → その成果で次の規模へ進む。

コウ自身が塔を登り、攻略の判断と危険を引き受ける。食堂で他人の冒険の報告を聞くだけにしない。畑と料理で遠征の力を作る → 仲間と上層へ挑む → 農業の知識と技能で仕掛けを突破する → 希少な種・素材・拠点の利用権を得る → 新しい栽培と料理で次の遠征を強くする、という循環を主軸にする。

圧勝の場面では、成功したか分からない説明で締めない。売れた食数、次の予約、指名した人物、獲得した契約などを画面で示す。コウとエルナも喜び、手にした成果を使う。毎回最後を破損・欠品・赤字へ戻して、勝利を帳消しにしない。

農業の仕組みは圧倒的な成果を納得させる土台にする。検証が続く区間にも、その時点で勝てる味、出荷の正確さ、価格に対する満足、設備の扱いやすさで小さな報酬を返す。通常は2〜3話のまとまりに一つ目に見える成果を置き、大勝利まで20話待たせない。頻度は事件に合わせて調整し、毎話同じ拍手と称賛を繰り返さない。

## 第11〜20話の狙い

| 話数 | 無双の見せ場と反応 | 手にする報酬・次への期待 |
| --- | --- | --- |
| 11〜12 | 十二食を受け取った攻略者が仲間を連れて戻る。小さな店に客が集まり、予定した営業枠が埋まる。以前は空いていた席と今の賑わいを対比する | 売上と翌営業日の予約。コウとエルナが初めて「選ばれる店」を実感する。まず成功を味わわせてから注文増への対応へ進む |
| 13〜15 | 同じ予算と入手可能な食材で出す試食の場を作る。農夫の仕事を軽く見た取引相手が、食べた攻略者たちの反応と提供の確かさに言葉を失う。調理の決め手はエルナ、収穫・選別・配膳計画の決め手はコウに帰属させる | ギルドから次の納品への指名。金額・食数・納期を確認して受ける。相手は実力を認め、好条件を提示する。味の勝利を契約の話だけで終わらせない |
| 16〜18 | コウが攻略隊と初めて四階へ登る。剣だけでは突破しづらい未攻略分岐で、根と水路のつながりを見抜く。現地で確かめた弱点を使って足場と攻撃の道を作り、剣士と魔法使いが決着する。「農夫を連れてきて正解だった」と戦場で評価が反転する | 未攻略区画の突破、希少な種と素材、次の探索への指名。13〜15話に同行の目的・戦闘担当・帰還までの店の役割分担を置く。コウの観察と指示を突破に不可欠な仕事として描く |
| 19〜20 | 自分たちで獲得した種と素材を持って帰還する。コウの攻略への貢献が食堂へ客と次の依頼を呼ぶ。名のある攻略者が、自分の隊の次の便と同行を頼む。満席の店、報酬、仲間との祝杯を披露する | 攻略報酬と予約が次の育苗・道具への投資になる。種はバルトと試験栽培し、収穫後の新料理への期待を残す。店を任せる仕組みと次の五階への目標を得る |

第10話終了時の営業枠は、自給と仕入れを合わせた16食。第11話で突然百食や全48m²の安定収穫へ飛ばさない。満席・予約・指名はその規模でも強く演出できる。将来の大口納品には、作期の経過、仕入れ、雇用、厨房能力を積み上げる。

四階はコウが初めて登る階であり、塔全体で初めて到達する階ではない。既に七階へ向かう攻略隊がいる設定を保ち、四階の未攻略分岐を局地的な初突破にする。帰還食堂はエルナが運営を担い、コウ不在時の畑の仕事をバルトたちへ渡す。不在でも残る店と、前線へ進む主人公を同時に育てる。

## コウが登る階と目的

| 範囲 | コウ自身の行動と到達目標 |
| --- | --- |
| 16〜20 | 三階から四階へ。初遠征、未攻略分岐の突破、種・素材の獲得と帰還 |
| 21〜40 | 四〜五階の探索。持ち帰った種の試験栽培と、次の産地・水源・採取地の攻略を往復する |
| 41〜80 | 七階へ同行し、前線の難所突破と厨房・農地の開設に自分で関わる。三階の仕事は仲間へ任せる |
| 81〜120 | 十二階へ進み、新しい環境と補給路の攻略を行う。三階の水配分と接続する判断を現地で担う |
| 121〜180 | 十二階より上の未攻略区画へ。多年生作物を育てる時間には遠征・拠点整備を並行し、三階で収穫待ちだけを続けない。大規模障害でもコウは前線の復旧と帰還路を切り開く |
| 181〜240 | 上層設備から頂層の制御区へ。本人が踏破し、仲間の戦闘とコウの生産・設備の判断を同じ攻略の決着へ集める |

戦闘職の仲間が剣と魔法で活躍し、コウは地形、水、根、育てた素材、遠征食を勝ち筋へ変える。コウにしかできない仕事を一つ示して終わらず、実際に敵の優位を崩して道が開く結果まで描く。〈耕作者〉の技能成長も遠征で使える報酬にし、新技能の範囲と消耗は世界設定へ先に置く。

## 長期の大勝利

| 範囲 | 既存の仕事から作る大きな快感 |
| --- | --- |
| 21〜40 | 四〜五階でコウ自身が獲得した種・素材と、バルトの在来知識、コウの比較試験が結び付く。同じ土地・条件で違いの分かる苗と畑を披露する。試験を見ていた農家が、自分たちから種苗の共同調達を頼みに来る。コウの成功は仲間の仕事と収益にもなる |
| 41〜60 | 大手が通せなかった補給の条件を解き、コウ自身も七階への隊に加わって難所の初突破へつなげる。戦闘の決着に続いて、前線で届いた食事と帰還後の指名を見せる。「あの農夫がいなければ勝てなかった」という具体的な評価と、七階の厨房を担う契約を得る |
| 61〜120 | 寒冷区画の作付け、熱の回収、水の配分を解くたびに、使える農地と供給先が広がる。維持費や気候に阻まれた場所で実際の収穫を披露し、技師・住民・依頼主の驚きを描く。上層から招かれる立場へ変わる |
| 121〜180 | 長く育てた作物の初収穫が客の歓声と注文になる。大規模障害では、蓄積した備蓄と代替輸送が働き、止まった町で帰還食堂の連合だけが約束した食事を届ける。信用が名声と運営の発言権になる |
| 181〜240 | 最強の攻略者たちが、コウの生産と補給を頼りに頂層へ進む。塔の制御を握る相手に、すでに生活を守っている拠点と住民の支持を示す。小さな畑から始めた仕事が塔を動かす力になったことを、動く設備、食事、仲間の選択で回収する |

## 脚本化するときの条件

- 軽視する人物には利害と判断の根拠を持たせる。全住民を無知にせず、バルト・イリス・レオンの専門性を保つ。実力を認めて協力者になる相手も作る。
- 苦労を長くするだけで反動の快感を狙わない。主人公が先手を打ち、優位に仕事を進め、積み上げた強さを使う区間を作る。
- 農業、料理、設備、輸送の貢献を分ける。仲間が活躍しても、コウの判断がなぜ勝利を可能にしたかを読者に見せる。
- 収量・人数・契約・設備が増えたら、次話にも残す。新しい課題は獲得した規模から生み、成功前へ巻き戻さない。
- 未設定の料理バフ、瞬間栽培、戦闘能力を突然追加しない。能力や作物の新要素を導入する場合は、世界設定、条件、発見、試用を先に脚本へ置く。

この構成方針と制作上の説明は制作資料に置く。読者向けのタイトル・紹介・話一覧へ「無双強化版」などの制作ラベルを付けない。
