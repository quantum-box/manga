# 天塔の剣士（仮題）

剣と魔法の王道ファンタジーに、MMORPGのパーティ攻略・装備成長・ギルド競争と、因果を追える魔法工学を組み合わせる新作企画。

入口は [制作設定](series/bible.md)。[世界観](series/world.md)、[魔法と塔の技術](series/magic-engineering.md)、[人物](series/characters.md)、[連続性と未決定事項](series/continuity.md)、[制作状態](production/status.md) を正本とする。

2026-10-06時点では企画・設定の初稿。作品の土台と全体話数はユーザーへ質問中で、採用確定ではない。ロードマップ・各話脚本・作画は未制作。完成漫画として既存カタログへは登録しない。
