## 改稿

前半の町の温かさに対し、後半40コマで帰還者との衝突を置いた。荷運び人の転倒、抗議する航への乱暴、抜刀を止めるリゼ、後始末で震える手、稽古の依頼を描く。討伐募集は明るい憧れから「強ければ止められたのか」という問いへ変えた。銅貨二枚は残り、パンは買えていない。

## 確認
