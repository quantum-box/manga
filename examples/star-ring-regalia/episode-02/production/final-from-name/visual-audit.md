# 本作画の確認

24原画を全件目視し、話者の尾・青い扉・銅貨二枚・水車の作業場・ブーツ・退場済み人物の背景を補修した。

元の一律2×2切り出しではf03の不均等な境界から次のコマが混入したため、source-crops.jsonに実際の境界を記録して全原画を再表示した。360pxの重なりつき通読画像を冒頭から結末まで確認し、390pxでは要所と寸法を確認した。台詞の欠け・隣接セルの混入は解消。

数値はmeasurements.json、原画の採用と生成元はplan.json、オフライン復元ハッシュはoffline-hashes.jsonを正本とする。公開と実機確認はこの時点では未完了。
