# 第3話の完成カラー原稿

2026-10-11の「うんok」で採用した85コマのネームを組み込みimage_genで完成カラー20原画に仕上げた。全63発話も画像生成し、独立した白地の声60個は15枚の吹き出し原画、絵の3個は場面原画に含める。採用本文・順番・表示窓・間を保持する。

場面原画は `../../art/f01.png`〜`f20.png`、白地の声は `v01.png`〜`v15.png`。vはvoiceの識別子。生成PNGの画素は加工しない。部分編集入力 `source-*.png` と実使用指示を保存し、採用元・SHA-256をstate.json、lettering/state.json、art-provenance.jsonで追える。

再構築は `python3 build-reader.py`。承認ネームのHTMLハッシュが変われば停止する。ルートの制作スクリプトもこの手順を呼び、採用構成を保持する。HTMLで見えるセリフ・吹き出し・効果音を重ねない。

render-review.cjsで390×844と360×800の全113画面を描画し、audit-layout.pyで純余白を算出。全63発話の字形・列・句読点と輪郭／尾を両幅で目視確認。verify-source.pyは85コマ、63発話の承認本文、35原画を照合する。単独リーダーの場面20PNGは全バイト一致、声15PNGはIDATだけ可逆圧縮し展開画素とその他チャンクが一致。正本の生成PNGは未変更。

CI・レビュー・サーバー公開はPR #94で進める。実機の確認は未実施。
