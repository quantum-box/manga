# 第3話の完成カラー原稿

2026-10-11の「うんok」で採用した85コマのネームを組み込みimage_genで完成カラー20原画に仕上げた。縦書き吹き出し60発話と絵の3発話、表示窓、順番、間は採用構成を保持する。

原画は `../../art/f01.png`〜`f20.png`。生成PNGの画素は加工しない。最新原画の部分編集入力は `source-*.png`、実使用指示は `prompts/` に保存。編集済み原画の採用とSHA-256はstate.jsonとart-provenance.jsonに記録する。

再構築は `python3 build-reader.py`。承認ネームのHTMLハッシュが変われば停止する。ルートの制作スクリプトもこの構築手順を呼び、以前の均等な原画列で上書きしない。

確認はrender-review.cjsで390×844と360×800の全画面を描画し、audit-layout.pyで純余白を算出する。verify-source.pyは85コマの構成、60発話と3発話、単独リーダーの20PNGが採用元と一致することを照合する。review/full-390.pngとfull-360.pngが完成縦読み画像。
