対象: full_episode。通常話。白黒ラフと編集可能な文字だけで構成を確認し、採用後に本作画を行う。

## 分量の予定

- 有効96コマ。候補99のうち同じ瞬間・同じ判断を重複する3コマを除外。画像17枚やDOM件数をコマ数に換算しない。
- 幅390 CSS pxで本編34,000〜60,000px、純余白を除いた内容24,000px以上。実量は読み込み・字体の確認後、validation.jsonに記録する。

## 主筋

1. 日本で朝の小さな仕事を終え、剣を学ぶ目的でミルトへ戻る。
2. 盾で剣道の癖が使えず、持ち方・距離・限界・休み方を教わる。借り物の責任を約束する。
3. 川の巡回で先走る帰還者が倒れ、航は負傷兵を守る。追撃より歩いて連れ帰ることを選ぶ。
4. 再生成・失われる装備・有限の補給と、治療を待つ現地の身体・交代する仕事を知る。
5. 片付けと盾の返却を済ませ、稽古で学んだ防御を怜に認められる。討伐への誘いが次の話の問いになる。
