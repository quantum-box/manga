# 第3話の確認資料

採用ネーム96コマを、40組の二コマ原画と16枚の単一コマ原画、計56枚に割り当てた完成原稿。全編を390×844と360×800で通読し、全56枚の読み込み、文字、接続、横あふれの不在を確認した。

- `continuous-390-01.jpg`〜`continuous-390-27.jpg`：390px幅、1600pxずつ、隣接40px以上を重ねた全編。
- `continuous-360-01.jpg`〜`continuous-360-25.jpg`：360px幅で同じ全編。末尾は前画面と重なる。
- `native-390-*`・`native-360-*`：実際のキー操作で構え、純余白、獣の出現まで進めた一画面。草の音は原画の一つのガサから点へ続き、880px幅換算の余白の後に獣が現れる。
- `standalone-360-*`：オフライン用`reader.html`と同じフォルダーの四個の`reader-art-*.js`で、全56枚の復元・読み込みを確認した冒頭と末尾。
- `complete-390.jpg`：全長の完成リーダー。原画を加工した縦長画像ではなく、ブラウザで描画した全長スクリーンショット。

390 CSS pxで本編高40,734.08px、外側の純余白4,470px、原画中の全面近白色帯207.21pxを除いた内容区間36,056.87px。有効96コマ。通常話の基準を満たす。360pxでは本編37,600.51px、内容33,283.24px。

`browser-checks.json`に実表示寸法と全編の座標、`pure-gap-source-bands.json`に全面近白色帯の検出結果、`artwork-provenance.json`に生成元と保存PNGの同一性を記録。本文やiOSには採用56枚だけを使用し、最新版の生成・編集が実際に参照する原画は制作資料として残す。不採用救助構図の四枚はGitの`742418e5`で管理し、作業ツリーから除いた。旧53場面のリーダーと確認画像は置き換え、旧本文はGit履歴で管理する。
