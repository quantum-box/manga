## 構成の変更

補欠の悔しさと弁当店の手伝いから、自分で買ったヘッドセットを選ぶ。母との九時の約束を持って接続し、草、足、身体、影、羽音、瞳の星環、空の全景へ進む。

灯里との別れの後、剣の重さを試す。荷車を助けた拍子に古い縄が切れ、薬箱が水路へ滑る。縄の予兆、車輪の衝撃、断裂、落下、航のキャッチ、リゼと引き上げる動作、安堵まで描く。薬箱は水面上で止まり、中の薬は守られる。名乗りと仕事の説明から、水路、薬を冷やす魔導器、意思のある精霊、自分の魔法の練習へつなぐ。

役に立ちたくて薬の依頼を引き受けるが、20:50の表示で九時の約束を思い出す。正直に伝え、一つの薬包みをリゼへ渡し、安全拠点から帰る。日本の21:00と母の声を受け、名前を呼ばれた実感で終える。薬は翌日にリゼの配達結果として引き継ぐ。

## 今回のフィードバック

驚き・呼びかけ・制止・合図の「！」と自然な問いの「？」を発話ごとに選んだ。通常の楕円、問いの丸い縦長、安堵の柔らかい輪郭、切迫したトゲ、心の声の点付き雲形を使う。ネームは無彩色とし、輪郭・線の太さ・尾・点から声の差が分かるようにする。色は本作画で検討する。

荷車の手助けを、薬箱の落下という小さな事件へ変更。剣も魔法も使えない航が反射的に人の仕事を守り、リゼとの共同行動とセナの後の依頼につながる。最終原画への進行は構成採用後。
