## 構成の変更

補欠の悔しさと弁当店の手伝いから、自分で買ったヘッドセットを選ぶ。母との九時の約束を持って接続し、草、足、身体、影、羽音、瞳の星環、空の全景へ進む。

灯里との別れの後、剣の重さを試す。荷車は失敗、手と足場の置き直し、合図、持ち上げ、車輪の脱出、相手の安堵まで描く。名乗りと仕事の説明から、水路、薬を冷やす魔導器、意思のある精霊、自分の魔法の練習へつなぐ。

役に立ちたくて薬の依頼を引き受けるが、20:50の表示で九時の約束を思い出す。正直に伝え、一つの薬包みをリゼへ渡し、安全拠点から帰る。日本の21:00と母の声を受け、名前を呼ばれた実感で終える。薬は翌日にリゼの配達結果として引き継ぐ。

数値の正本は `validation.json` と `review/layout-*.json`。本編は `#preview-flow` の実際のCSS寸法で測り、ヘッダー・注意書き・計測UIを除いた。純余白は絵と文字の占有区間の和集合から空の縦帯を求め、p091の画像内の下端22%の無情報帯も除いた。声・音の要素内の空白、相対配置の空白も数えている。画像の保存寸法や枚数で本編高を代用していない。

96カットのうち、移行、位置確認、同じ動作の補助として12カットを保守的に除外した。声・音・余白の要素は有効コマに加算しない。除外IDと各カットの新情報は `validation.json`、`storyboard.md`、`source-layout.json` に残す。

量・物語・水増しを別々に確認した。量は三基準を満たす。物語は選ばれない出発点、自分の選択、仕事への失敗と修正、相手の反応、暮らしの理解、帰る判断、その結果まで一話で閉じる。余白の増加や同じ瞬間の再分割で有効コマを増やしていない。

390pxの全編は前半を `visual-audit-first-half.md`、後半を `visual-audit-final.md` に記録。360pxの全編は `visual-audit-360.md`、修正後の重要場面は `visual-audit-final.md` に記録する。`review/windows-*.json` は120pxを重ねたネイティブ幅の連続画面。画像読み込み失敗、文字の横あふれ、吹き出しのコマ外あふれは両幅0。実機確認とユーザーの構成採用は未確認。
