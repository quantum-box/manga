# 星を拾う夜

SF縦読み短編。2026-10-04、`webtoon` スキルで制作。宇宙灯台の当直員ナギが小さな信号を追い、宇宙の親子を見送る一夜。

`reader.html` をブラウザで開き、下へスクロールする。画像をすべて内包した単独ファイル。サーバーや外部通信は不要。

## 今回の縦読み表現

短い操作コマ、下へ続く信号、小さな生物の接写、耳を澄ませる短いコマ、巨大な親の姿、見送りというリズムで組んだ。宇宙の長い背景と親子の縮尺差を使い、読む位置によって分かる情報を変える。最後は「来航ゼロ」から「来航、二頭」へ当直記録が変わる。

人物・作業着・生物の配色を参照画像で固定して6場面を組み込み `image_gen` で新規作画。日本語、吹き出し、音はHTML/CSSで別組版。原本は加工せず `art/` に保存。

## ファイル

- `reader.html`: 単独で開ける完成版。
- `webtoon-390.jpg`: 文字を含めた全体スクリーンショット、390×5188px。
- `index.html` と `art/`: 編集用の組版と原本。
- `storyboard.md` と `PROMPTS.md`: 構成、キャラクターの状態、実際の生成指示。
- `validation.json`: 表示確認の数値と目視確認事項。

## 表示確認

ブラウザで390×844 CSS pxと360×800 CSS pxを確認。すべての画像が表示され、セリフは最小19px。横あふれなし。「救難信号？」から子クジラの場面までの距離は約909px・841px。「返事が下から」から親の見え始めまでの距離は約921px・852px。それぞれ確認した表示高を超える。親の見え始めは画像内45%の位置で保守的に測った。

人物は窓の内側、生物は外側にいる。親は第5場面まで登場しない。最後の画像は大きな親と小さな子が一頭ずつ。前作の猫や駅の素材は流用していない。
