2026-10-04。「もっと余白を広く取り、スクロールさせる。間をうまく使う」という依頼に合わせた組版版。

## 読む間の変更

- 青いランプに気づいてから信号を追うまで、短い呼吸を置く。
- 子クジラの発見直前と発見後に別々の間を置く。
- 親の出現前に長い暗がりを置き、既存の「どくん」を姿より先へ移す。
- 巨大な姿を見たあと、親子を見送ったあと、最後の「異常なし」の前に余韻を置く。
- 計器を操作する小コマは密なまま残し、全場面を等間隔にはしない。

390×844 CSS pxでは全長7312px、360×800では6812px。390px幅の完成画像は[webtoon-390.jpg](webtoon-390.jpg)（390×7311px）。前版の390px幅での全長5188pxに対し、約41%長くなった。

390px幅で「救難信号？」の末尾から子の場面まで1263px、「返事が……下から。」の末尾から親の出現位置まで1545px。「どくん」から親の出現まで926px。360px幅でも、それぞれ1164px、1428px、854pxあり、確認した表示高より長い。

作画は組み込み画像生成で作ったv1の6枚をそのまま使用し、画像の加工や追加生成は行っていない。[PROMPTS.md](PROMPTS.md)に元の作画指示を残している。文字・余白・効果音の位置はHTMLで編集できる。

[validation.json](validation.json)に実際のCSS表示範囲、画像の読み込み、文字、情報間の距離を記録した。ブラウザの80%倍率に合わせてキャプチャの範囲を補正し、最後まで目視で確認した。
