# 第1話 最弱判定、最強の一歩。

会話・状況・大小の枠を改稿：33画像・73コマ。

コマ割りを4素材で再構成。手を差し出す動作と返事、礼と目元の反応は同じ段で右→左へ読む横並び。装甲固定は前腕と脚を斜めのコマ間でつなぎ、胸は全幅。空中の救出は上下の外枠を傾けた大コマにした。既存のセリフ・効果音・出来事・コマ数は維持。[4例の一覧](review/layout-sequence-390.png) / [制作・確認記録](../production/episode-01-layout/README.md)。

効果音を既存11素材で追加・強化。手を伸ばす・握る・水晶に触れる・救出・巨兵の足音を増やし、雨、崩落、落下、起動、打撃の音と描き分けた。効果音のある場面は4→17、計24語。装着過程を3素材・7コマで追加し、核の光が腕へ伸びる→前腕・脚・胸を固定→拳を動かす→残量と接続完了を確認→全身の決めゴマへつなぐ。既存の会話と救出後・最後の手掛かりの静けさを維持。

[効果音の制作・確認記録](../production/episode-01-sfx/README.md)。360/390px幅のネイティブ画像と前後の連続窓で目視済み。リーダーZIP・iOS同梱版も更新。ブラウザのfile URLは安全制限で拒否されたため、DOM・ブラウザ画面と実機は未確認。
