# 第1話 最弱判定、最強の一歩。

[全編を読む](index.html) / [単体ZIP](reader.zip) / [390px幅の全編PNG](complete-390.png) / [360px幅の全編PNG](complete-360.png)

第1話全編を余白とスクロールの演出で組み直した採用版。原作の73コマ・既存のセリフと効果音を維持し、76の表示単位に分けた。40枚の原画を使用し、同じ原画の複数コマを見せる場合も単体HTMLには1回だけ埋め込む。

測定を待つ「そのまま、待て。」、何もできないという思い、遠くの振動、救出前の決意、装着音、接続完了の通知を白い余白で読ませる。薄い光の軌跡を送った後で全身装甲が現れる。小さな動作は短くつなぎ、魔力ゼロの結果・救出後の安堵・最後の紋章の発見には長い間を取る。手と返事、お礼と反応は横並び。腕と脚の装着は斜めのコマ間。

余白へ移した言葉と音は元のコマで繰り返さない。飛び出す絵から決意の吹き出し、装着する絵からカチッを組み込み image_gen で除去。足元の振動は文字なしの新規作画。余白の通知・クリック・光にはユーザー採用見本の原画をそのまま使用。絵・縦書き・効果音は原画に収録し、HTMLでセリフを重ねない。
