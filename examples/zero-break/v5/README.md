# 第1話 最弱判定、最強の一歩。

会話・状況・大小の枠を改稿：30画像・66コマ。

効果音を7場面で追加・強化。雨の「ザァァ…」、橋の「ゴゴゴ…」「バキバキッ！」、落下の「ヒュウウッ」、飛び出しの「バッ！」、起動の「キィィン…」、装甲の「ガキンッ！」、打撃と破砕の「ドゴォンッ！」「ガシャァッ！」を画像内に描き込み。効果音のある場面は4→10、計12語。救出後の会話と最後の手掛かりには静けさを残す。

[効果音の制作・確認記録](../production/episode-01-sfx/README.md)。360/390px幅のネイティブ画像と前後の連続窓で目視済み。リーダーZIP・iOS同梱版も更新。ブラウザのfile URLは安全制限で拒否されたため、DOM・ブラウザ画面と実機は未確認。

絵・吹き出し・日本語の縦書きセリフを組み込み image_gen で一緒に生成。旧原画は保持。改稿素材の実行指示、参照のハッシュ、修正前後は generation-log.json と ../production/feedback-v6/records に保存。

全長画像は manifest の寸法と配置からネイティブCanvasで書き出した画像。ブラウザの画面撮影ではなく、HTMLの画素一致・DOMの実表示・実機の証明には使わない。360px幅の全素材と390px幅の代表区間で全文、話者、顔・手、小道具、因果を目視。ブラウザ再確認と実機確認は未実施。

原画と単体HTMLの埋め込みPNG、ZIPのCRC・展開後のHTML、iOS同梱版をバイト照合。検査状態は validation.json、raster-export-validation.json、delivery-validation.json。
