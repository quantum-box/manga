# ゼロ・ブレイク

**最新版：[第1話・縦書き v5を読む](v5/index.html) / [縦読み完成画像](v5/complete-390.png)**

異世界転生 × スーパーヒーロー。全50話で完結する短編連載企画。

- [第1話の編集用HTML](v5/index.html)：画像の配置と余白を編集できる。セリフと吹き出しは原画に含む。
- [第1話の絵コンテ](v5/storyboard.md)：30場面で接近、魔力測定、結果への反応から救出と覚醒までつなぐ。
- [全50話の脚本を読む](series/index.html)：話選択つきの目次と場面脚本。
- [個別脚本の目次](series/README.md)：全50話、300の大場面。
- [設定・能力の制約・伏線台帳](series/bible.md)。
- [作画指示](v5/PROMPTS.md) / [表示検証](v5/validation.json)。

第1話 v5は、騎士の説明と判定を詰め込んでいた2枚を16場面に置き換え、全30場面へ拡張した。足音、遠くから近づく騎士、声かけ、立ち上がる、空の国への戸惑い、装置まで歩く動作を描く。測定は説明→迷い→接触→待機→ゼロ表示→聞き返す→意味を知る→落胆の順に進む。救出以降の採用原画は保持し、新しい16枚も絵・吹き出し・縦書きセリフを一緒に生成した。スマホ2サイズの表示と目視確認は表示検証へ記録する。

2〜50話は場面脚本が完成、作画は未制作。各話6つの大場面を、必要な状況・行動・反応のコマへ分けて描く。全話の元データは `series/episodes.tsv`、脚本閲覧HTMLの再生成は `python3 series/build_scripts.py`。

原画は組み込み画像生成を使用。原画、全生成指示、修正前の画像を保存。文字を変える場合は対象の画像を再編集し、余白や配置はHTMLで変更する。[v5の制作ファイル](v5/README.md)。単独で開ける版は[ZIP](v5/reader.zip)を展開し、`reader.html` を開く。リポジトリには採用したv5と生成に使用したv4の参照原画・指示を収録する。

第1話 v5の再構築と検証（このディレクトリで実行）：

```sh
python3 v5/build_reader.py
python3 v5/package_delivery.py
npm install --no-save --package-lock=false playwright pngjs
node v5/check.cjs
```
