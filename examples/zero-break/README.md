# ゼロ・ブレイク

**[第1〜10話を縦読みで読む](chapters.html)**

異世界転生 × スーパーヒーロー。全50話で完結。改稿版 context-dialogue-v6：第1〜10話は199画像・556コマ。第11〜50話はコマ別脚本を更新し、作画は未制作。

会話を発言→受け手→続きへ分け、人物や対象の接写へ焦点を移す。導入と危機では位置関係を見せ、コマの幅・高さ・左右位置・枠の有無を読む時間に合わせて変える。楕円、柔らかい声、揺れる声、叫び、思考、資料枠を使い分ける。

第1話は[効果音と装着過程を追加](production/episode-01-sfx/README.md)。既存11素材の効果音を編集し、光の経路→部位ごとの装甲固定→動作・残量確認を3素材・7コマで追加。効果音は17場面・計24語。既存の会話と全身の決めゴマを保ち、33画像・73コマへ更新。

さらに[第1話の4素材のコマ割りを改稿](production/episode-01-layout/README.md)。会話と反応を横並び、装着を斜めのコマ間、救出を傾いた外枠にした。広い状況確認と全身の披露を残し、同じ33画像・73コマ、同じセリフと効果音で読む強弱を変えた。
