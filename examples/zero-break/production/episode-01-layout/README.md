# 第1話の横並び・斜め枠の改稿

[第1話を読む](../../v5/index.html) / [単独リーダーZIP](../../v5/reader.zip) / [4例の一覧](../../v5/review/layout-sequence-390.png)

縦に積むだけの配置を、場面に合う横並びと斜め枠へ4素材で変更。組み込み image_gen の出力PNGを無加工で採用し、編集元4枚を保持。第1話は同じ33画像・73コマ、効果音17場面・24語。既存のセリフ、出来事、装着と全身の披露の順は維持。

| 素材 | 構成と目的 |
| --- | --- |
| e01-greeting | 上に問い、中央右に差し出す手・左に返事、下に握って立ち上がる。短い動作と応答を横へ読む |
| e01-catch | 空中の救出を上下の辺が傾く大コマへ。背中と膝を支える手、顔、叫びを広く見せる |
| e01-safe-01 | 全幅で安全と二人の位置を確認。中央右に礼・左に浅い目元の反応、下に広い名乗り |
| e01-armor-assemble | 上段右の前腕から左の脚へ、斜めのコマ間で固定音をつなぐ。下段は胸の固定を全幅で見せる |

同じ段は右→左、段は上→下。横の小コマは目や手、部位へ寄り、文字や全景を小さく詰めない。救出の吹き出しは上の斜辺を越えるが、文字は正立し、キャンバス内に収まる。

## 制作と再構築

`plan.json` に実際の生成指示、`outputs.json` に生成元とハッシュ、`records/*.json` に編集前の各素材、採用PNG、変更した枠、段ごとの読順、参照のハッシュを保持。`baseline/` は今回のコマ割り変更前の構成・指示・確認記録。

`python3 examples/zero-break/v5/build_reader.py` で効果音と装着の変更を適用後、今回のコマ割りを再適用する。前段階の記録へ戻しても、セリフ・音・各コマの出来事が一致することと編集元の保存ハッシュを照合してから再構成する。生成ログと絵コンテ、単体リーダー・ZIP、iOS同梱版、全50話の脚本の第1話へ反映。第2〜50話の脚本文字は保持。

webtoon skillはリポジトリ版とインストール版の両方へ、判断基準・作画指示・同梱画像を追加。今回の4例は制作例として記録し、ユーザーによる評価は未記録。

## 確認

360/390px幅のネイティブCanvas画像で4素材の全文、横並びの右→左の順、実際の斜め枠・コマ間、顔と支える手、人物の同一性を目視。前後の連続窓で手を貸す場面から名乗り、跳躍→空中の救出→着地、礼→名乗り→身分、光の格子→部品固定→拳と残量の確認→全身の披露を確認。

未変更29素材は変更前の保存済みSHA-256と一致。4枚の採用PNGは組み込みツールの出力とバイト一致し、変更前4枚も保持。原画・HTML内の埋め込みPNG・ZIP・iOS同梱版、効果音11編集・装着3追加の出所を照合する。
