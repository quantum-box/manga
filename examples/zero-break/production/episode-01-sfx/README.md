# 第1話の効果音改稿

[第1話を読む](../../v5/index.html) / [単独リーダーZIP](../../v5/reader.zip) / [360px全長](../../v5/complete-360.png) / [390px全長](../../v5/complete-390.png)

組み込み image_gen で採用原画7枚を部分編集。元画像を参照し、効果音と小さな動線のアクセントを画像へ一緒に描き込んだ。出力PNGは無加工で `v5/art/sfx-*.png` へコピーし、従来の原画は同じartディレクトリへ保持。

|場面|音と役割|
|---|---|
|前世の雨|ザァァ…：静かな雨の記憶|
|橋の崩壊|ゴゴゴ… / バキバキッ！：巨兵の重さと石橋の破断|
|落下と飛び出し|ヒュウウッ / バッ！：落ちる風とレンの決断|
|核と装甲|キィィン… / ガキンッ！：起動音から硬い装甲へ|
|打撃|ドゴォンッ！ / ガシャァッ！：主打撃を大きく、石の破砕を小さく|

効果音のある場面は4から10へ、計12語。従来の足音、最初の地響き、着地音を維持。救出後の自己紹介、安堵、王家の紋章には音を足さず、静かな間を残す。会話・ナレーション・システム文字、順序、30画像・66コマ、表示幅・余白を維持。

## 制作記録

`plan.json` は実行した編集指示、`outputs.json` と `records/*.json` は生成元・採用ファイル・参照とSHA-256。`baseline/` は改稿前のmanifest・実行記録・HTML・絵コンテ・指示・検査結果。各採用記録にも編集元と旧ハッシュを保存。

再構築は `python3 examples/zero-break/v5/build_reader.py`。効果音の記録を再適用するため、旧構成へ戻らない。生成文字はHTMLへ重ねず、効果音の全文をaltと絵コンテにも記載。

## 確認

360pxと390pxのネイティブ画像で7素材すべての効果音・既存文字・顔・手・衣服・小道具を確認。崩落から落下、飛び出しから受け止め、起動から装甲、打撃から安堵、最後の手掛かりまでの連続窓も目視した。未編集23素材と旧原画7素材のハッシュ、原画・単独HTML・ZIP展開結果・iOS同梱版を照合。

結果は `verification.json` と `../../v5/validation.json`。ネイティブ書き出しはブラウザ画面ではない。Browser Useでfile URLが安全制限により拒否されたため、ブラウザのDOM・スクロール確認は未実施。別ブラウザやlocalhostで迂回していない。iOS実機と公開サイトへの反映は未実施。
