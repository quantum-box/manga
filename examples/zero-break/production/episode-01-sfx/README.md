核から光が腕へ伸び、素手の手首へ格子ができる。黒い前腕・脚・胸の装甲を順に固定し、拳を動かして「……動かせる。」と確認。救済核残量は六区画中四つ点灯、接続完了を示してから、一拍置いて既存の全身決めゴマへ進む。物理的な装着と有限の残量を絵で伝える。核の由来、将来のフォーム、数値の消費量や制限時間は追加しない。

## 制作記録

`plan.json` / `outputs.json` は第1段階の7枚、`pass-2-plan.json` / `pass-2-outputs.json` は追加4枚と装着3枚。`records/*.json` と `inserts/*.json` に実行指示・生成元・参照・SHA-256を保存。`inserts.json` が挿入順と核の通知後の間を指定する。`baseline/` は効果音追加前、`pass-1-baseline/` は最初の7枚を追加した時点の記録。

拳の思考吹き出しが手を指していたため、image_genで点だけを画面上のレンの頭方向へ修正。修正前の `armor-check-before-thought-tail.png`、初回指示、修正指示、双方のハッシュを保持。

再構築は `python3 examples/zero-break/v5/build_reader.py`。効果音と装着過程の記録を再適用するため、旧構成へ戻らない。生成文字はHTMLへ重ねず、全文をaltと絵コンテにも記載。
