# 天魔、二周目。

武侠ゲームを三千時間やり込んだ学生が、冤罪で処刑される雑役弟子に転生。レベル999と全武技を引き継いだ体でも、本人は痛みと死を怖がる。強すぎる力に戸惑う青年が、生き残って帰るため武林を進む、鮮明なセル塗りのアニメ風Webtoon。

第1話：**処刑する相手、間違えてるぞ**。

## 第1話・感情改稿版

名前も場所も分からない恐怖、昨日までの日常、夢であってほしい気持ち、縄で確かめる力。処刑の刃を止めた本人が驚き、再攻撃を押し返すと長老が吹き飛ぶ。相手が生きていることを確かめ、遅れて手が震える。最初の勝利を、周囲の驚きより先に本人の生還として描いた。

第1話の山場は長老との一戦に絞る。天魔剣の姿と臣従、隠しルート開放は第2話へ移し、音だけを引きにする。

作画10種類を17の表示窓に組み、会話はHTMLで組版。ステータス3点は、文字とシアンの枠が柔らかくにじむ、視界内のシステム投影。効果音5点・武技名1点とともに透明背景の生成画像を使う。表情の編集3枚と、攻撃の因果・戦闘後の反応の新規作画2枚を加えた。

360×800／390×844 CSS pxで確認。セリフは19px以上、横はみ出しなし、26画像が表示済み。iOSの作品カタログにも収録。制作と編集の詳細は [episode-01/README.md](episode-01/README.md)。完成した本文は第1話のみ。第2〜5話は企画段階。
