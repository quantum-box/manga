# 天魔、二周目。

最強の身体でも、死ぬのは怖い。ゲームで聞かなかった声を聞く二周目。

剣を盗んだ罪で処刑されるはずだった雑役弟子は、見知らぬ世界で目を覚ます。死を免れる力を持っていても、自分の罪も帰り道も分からない。証人の言葉と証拠をたどり、自分の名前を取り戻そうとする。
