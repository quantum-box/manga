# 塔を灯す剣

[第1話から読む](episode-01/index.html) · [第1〜10話の一覧](chapters.html)

VRMMORPG《星環の塔 ONLINE》を舞台に、自分の作った剣で塔の頂上を目指すカイと、盾役のセナ、魔法使いのイリスを描く初稿。剣と魔法の王道の冒険に、有限の部品で作る装備、試験、連携、共同工房を組み込む。

## 制作範囲

2026-10-07、読者から初稿の密度、1話の短さ、展開の速さ、状況と共感の不足を指摘された。第1話を描き直し、登りたい動機、セナとの関係、試作品の不具合、確認、試験、勧誘の意味を順に見せる。追加指摘を受け、現在は68コマ・18枚の原画。ステータス、装備詳細、試験ログ、パーティ参加を実際の操作として追加し、《灯刃・試作》の効果とカイの得意分野を見せる。停電は第2話へ送り、第1話は一緒に登る約束で終わる。第2〜10話は初稿・改稿待ちであり、完成と扱わない。

台詞と縦書きの吹き出し、横書きのHUDは原画に一体生成。各話の `index.html` は画像参照式、`reader.html` は画像を内包した単一HTML。第1話の全長記録はブラウザーから上下2分割で保存した `webtoon-390-part-01.jpg` など4枚。順序と範囲は `validation.json` に記録。第2〜10話の `webtoon-390.jpg` と `webtoon-360.jpg` は初稿の全長画像。原画と台詞の増加だけで、読者が理解できると確定しない。

第1話は発話と効果音を別に設計し、7枚の部分編集で13箇所の動作音を整えた。無言の動作にも音を入れ、聞く表情や安堵には無音を残す。効果音は吹き出しへ入れず、音源の近くに描き込む。実行済み指示は [PROMPTS-USED.md](episode-01/PROMPTS-USED.md)、修正済みで未実行の次回生成指示は [PROMPTS-NEXT.md](episode-01/PROMPTS-NEXT.md) に分けて記録。

HUDも発話・効果音と独立させた。灯刃は斬撃を30％強化する魔導剣。カイは市販型と同じ効果を半分のMPで出す回路を設計する。熱は強化の際に回路へ残る損失で、溜まると安全装置が強化だけを止める。回路設計68・剣術12という現在の技能を、成果と試験を伴って描く。新しい窓の入力には5箇所の短い電子音を加え、現在の効果音指定は計18箇所。

縦積みの密度への追加指摘を受け、8枚の構図を描き直した。塔・街の経路・最後の夕景を枠なしの縦の背景へ、短い二打と問い・返答を同じ段の右→左へ、三打目と成功後の安堵を待つ間へ分ける。装備の画面と再試験は別の縦横比を使い、全18枚を同じ1:3の縦横比と構成へ固定しない。物語上の68の瞬間、全文の台詞、HUDの内容、18音は維持。キャプチャと読順の確認は `validation.json` の `scroll_review` に記録する。

200話以上の指定に対し、[240話の全体構成](series/roadmap.md)を12アークで仮設計。第11〜240話は長期構想であり、完成作画や各話の詳細脚本ではない。改稿後の読み心地へのユーザー評価は未確認。

## 確認と再構築

390×844・360×800 CSS pxで画像読み込み、横はみ出し、画像内の縦書き、話者、所持品、場面の順を確認する。最新の実施状態は [制作状態](production/status.md) と各話の `validation.json` に記録。技術的な表示確認と、読者が流れを理解できるかは別の判断。物理スマートフォンやiOS実機の確認ではない。

```sh
python3 examples/tower-forge/production/build.py
python3 examples/tower-forge/production/verify.py
python3 scripts/sync_ios_webtoons.py
python3 scripts/sync_ios_webtoons.py --check
```

組み込み image_gen の原本を保存し、必要な修正だけ編集機能で作った。現行画像は `production/adopted-assets.json`、初稿の原本は `production/asset-provenance.json`、第1話改稿の原本と正確な実使用指示は `production/revision-provenance.json`。画像生成を再実行せずにリーダーを再構築できる。原本は現行版の編集元として残し、旧話版のリーダーは併存させない。旧本文はGit履歴から復元できる。

ローカルのカタログとiOS同梱データへ収録。配信サーバーへの公開、TestFlight配布、GitHubへの公開は実施していない。
