# 240話の仮ロードマップ

ユーザー指定は200話以上。12アーク×20話で240話まで抜け・重複なく設計する。遠い展開は主要転換までの仮案。第1〜10話のみ初回作画範囲。

| 話数 | 舞台・目標 | 対立と転換 | 決着して残るもの |
| --- | --- | --- | --- |
| 1–20 | リューメル／第一〜三層。自分の剣でパーティに入る | 灯炉復旧で三人が結成。後半は修理だけでは足りない剣術と遠征運営を学ぶ | 工房と定期パーティ。最初の正式攻略記録 |
| 21–40 | 森の第四〜十層。最初の門を越える | 可燃性植物と風魔法の相性。火力優先が探索路を焼く。イリスが魔法を選び直す | 森を保存する攻略法、第一の門解禁 |
| 41–60 | 水路の十一〜十八層と外の港 | 水中に火の刃は向かず、装備を更新。物流ギルドとの素材契約が足かせになる | 水に耐える装備、取引の条件を選べる信用 |
| 61–80 | 十九〜二十層の都市と共同工房 | カイの設計図の共有をめぐり利益と再現性が衝突。模倣品の不良を全て背負おうとする | 版と試験記録を伴うレシピ公開。自分以外の作り手が育つ |
| 81–100 | 雷の二十一〜三十層 | 盾の大きさが雷を集める。セナの防御観が崩れる。ヴェインと合同レイド | 違う守り方の習得、ライバルとの実績ある協力 |
| 101–120 | 地上の王国・塔の三十一〜四十層 | 争奪区域の競技と市場。現実の予定が重なり毎日参加できない | 交代できるチーム。遊ぶ時間と責任を相談する関係 |
| 121–140 | 空中群島の四十一〜五十層 | 運搬、重さ、射程の制約。新素材で巨剣を作る誘惑と、運べる小型装備の価値 | 遠征拠点と、誰でも扱える軽装の製作体系 |
| 141–160 | 五十一〜六十層、古代工房 | 敵にも魔力の回路がある。同じ出力の競争から、構造を読む戦闘へ進む | コアを壊さず停止させる技術、塔の歴史の局地的回収 |
| 161–180 | 六十一〜七十層、季節更新 | 強い組み合わせが調整される。運営と対話し、仲間の遊び方を守る | 再設計による別の勝ち方。アップデートで技能が無価値にならない根拠 |
| 181–200 | 七十一〜八十層、竜の前線 | 大規模連合で研究と指揮の責任を持つ。公開派・独占派が対立 | 検証情報を共有する連合、各チームの役割と合意 |
| 201–220 | 八十一〜九十層、白鷹との頂上争い | ヴェインの隊が先行するが補給が切れる。カイは救援で順位を失うか選ぶ | 競争を続けられる救援。依存ではなく互いの選択による連携 |
| 221–240 | 九十一〜百層。最終竜と星環の頂上 | 有限の部品を使い、違う設計が協力して攻略。剣術・盾・魔法・工房の蓄積を使う | 主対立の決着。自分の剣で頂上へ到達し、次のログインを工房で待つ |

第10話の灯炉復旧で小さな問題を閉じ、第20話で最初の攻略隊としての仕事を閉じる。120話以降も未回収の謎だけで牽引せず、既存の成功が物流・教育・研究・責任を変えることを事件の理由にする。

## 開示と人物の変化

塔の古代技術はゲーム内の歴史として、初回の刻線→森の燃焼制御→水路の流路→古代工房の設計思想と段階的に解く。ゲームそのものが異世界になる真相を後付けしない。

カイは10話で限界の共有、60話で契約、80話で公開の責任、140話で拠点の運営、200話で共同研究、240話で自分も戦う製作者へ。セナは30話で任せる配置、100話で他の盾役を育て、120話で交代できる隊、最終攻略で複数隊の防御を指揮する。イリスは40話で使わない魔法の判断、80話で試験共有、160話で敵の構造の研究、最終戦で他人の装備にも合う魔法を設計する。
