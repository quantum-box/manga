# 剣聖、仇の弟子に転生する — 第1話「知らない手」

白背景の長い導入回。目覚めから、自分が仇の弟子になっていたと分かるまでを描く。v1/v2の襲撃・救出・秘剣の成功はこの回に進めず、小さな動作と反応に尺を使った。

## 読む

`reader.html` は原画と文字を埋め込んだ単独HTML。JavaScriptが有効なブラウザでオフラインでも読める。編集用の原画は `art/`、文字と見せ順・余白は `episode.json`、組版は `reader.css` に分けた。生成時の指示と参照画像の出典は `prompts.json`、同じ参照画像の持ち運べるコピーは `references/` にある。

```sh
python3 build.py
python3 -m http.server 8770 --bind 127.0.0.1
```

`http://127.0.0.1:8770/reader.html` で読む。文字や間を調整したら `build.py` を再実行し、ブラウザを再読み込みする。

## 今回の尺と構成

- 14枚の原画。9枚を新規生成し、5枚を白背景v2から再利用した。原画のピクセルは変更していない。
- 45の表示範囲に分けて読む。手を開く、指を曲げる、握る、木刀を落とす、と動作ごとに進む。水滴から水鉢への構図は一続きに保つ。石段も下へたどる構図を残した。
- 動作の途中は短い間、落とした後や身体を確かめた後は長い間。水面の顔と、声の主の顔は、問いが消えてから現れる。
- 仇が差し出した手を取れないところで止める。既存 `09-disciple` は関係が分かる上部の全景だけを使い、重なる手の詳細描写は新規作画へつなぐ。同じ絵を反復して尺を増やしていない。

距離は問いの段落の下端から、答えの原画が始まる位置まで。確認した両サイズでは問いと答えが一画面に同時に入らない。全45表示範囲の画像読み込み、横幅、文字のはみ出しを確認した。目覚め、木刀、水面、傷、声、仇の顔、手のためらい、結末を実際に表示して読んだ。`validation/` に測定値とスマホの画面を保存した。

全長画像は `webtoon-full-390.jpg`（390×32,434px）。スマホの長さとして読むための画像であり、全体を一画面へ縮小して画質を判断しない。書き出しはブラウザから行った。ブラウザによる小数点の丸めがあるため、上表のChromeの全長と書き出しに使用したブラウザの全長には数pxの差がある。

4〜6分は読者で確認する目標で、読了時間は未計測。画面数をそのまま読了時間に換算しない。次の調整では、文字を足す前に実際のスクロールと視線の止まり方を見る。
