# 導入アーク

## 第1話 肉球の朝
森の小川で目覚めたポチが、身体と声の変化を確かめる。

不安で動けない → 助けを呼ぶ声 → 自分も怖いが探しに行く

## 第2話 伝わらない声
声が言葉にならないポチは、行動で子供の居場所を知らせる。

枝は動かせない → 探している姫の声 → 裾を引いて導く → 救助

## 第3話 ここにいる理由
助けた姫から居場所をもらい、村の困り事を知る。

世話され安心 → 自分にもできた → 渇いた村 → 姫が交渉へ行く理由

## 第4話 犬の歩幅
旅の危険を通して、助けるにも限界と協力が要ると知る。

追いつけない → 姫が待つ → 橋の欠落 → 水音を追って浅瀬確認

## 第5話 怖い顔の向こう
警戒する魔族の番犬を助け、城への最初の信頼を得る。

牙に恐れる → 鎖に苦しむと気付く → 許可を待って解く → 案内される

## 第6話 帰れと言う人
門前の拒絶と壊れた水路から、噂だけでは判断できないと気付く。

門前で拒否 → 水を求める → 水路の破損 → 強い風から退く

## 第7話 近づく前に
魔王を初めて見て怖がる。追い払う言葉と守る行動を両方見る。

風から助けられる → 警戒 → 事情を聞く → 話す許可を得る

## 第8話 一人では直せない
魔王の制約を知り、お願いを協力へ変える。

機構説明 → 二つの手が要る → 姫が手伝う選択 → 小さく試す

## 第9話 できることをする
修理中の危険を知らせ、ポチ自身も助けられる。

分担 → 緩む足場 → 吠えて知らせる → 二人が止めて安全確保 → 修理成功

## 第10話 おてから始まる
修理を確かめて水を戻す。恐怖を越えた握手が関係を変える。

安全確認 → 少量放水 → 村へ流れる → 感謝 → 自発的な握手
