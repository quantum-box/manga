# 連続性台帳（作画前の予定、完成後照合）

- 1: 不安で動けない → 助けを呼ぶ声 → 自分も怖いが探しに行く
- 2: 枝は動かせない → 探している姫の声 → 裾を引いて導く → 救助
- 3: 世話され安心 → 自分にもできた → 渇いた村 → 姫が交渉へ行く理由
- 4: 追いつけない → 姫が待つ → 橋の欠落 → 水音を追って浅瀬確認
- 5: 牙に恐れる → 鎖に苦しむと気付く → 許可を待って解く → 案内される
- 6: 門前で拒否 → 水を求める → 水路の破損 → 強い風から退く
- 7: 風から助けられる → 警戒 → 事情を聞く → 話す許可を得る
- 8: 機構説明 → 二つの手が要る → 姫が手伝う選択 → 小さく試す
- 9: 分担 → 緩む足場 → 吠えて知らせる → 二人が止めて安全確保 → 修理成功
- 10: 安全確認 → 少量放水 → 村へ流れる → 感謝 → 自発的な握手

F1 手を失う→2話は行動で知らせる→9話は声で危険を知らせる。
F2 3話のおて→10話の自発的な握手。
F3 3話の乾井戸→6話の閉鎖理由→8話の修理制約→10話の水。
F4 5話の威嚇の理由→7話の魔王も行動を見て判断。

星は常に一個、犬の右前足と魔王の右手。姫のマントは全話で維持。8話で畳んだ青布は携帯毛布で、9話の待機台に置く。水門は9話完了まで閉鎖、10話で少量開ける。第6話まで魔王の全身・顔・角を見せない。
