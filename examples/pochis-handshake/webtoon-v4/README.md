# 転生したら柴犬だった。 第1〜10話 改稿版

[全10話を続けて読む](all.html) · [話一覧](chapters.html)

展開の因果と反応を増やした完成漫画。全10話・40枚。縦書き会話は画像内に一体化。

| 範囲 | 進み方 |
|---|---|
| 1〜3話 | 柴犬の身体と声を確かめる → 子供を助ける → 姫に世話され、ついて行く理由ができる |
| 4〜7話 | 犬の歩幅で旅をする → 狼を助ける → 魔王の拒絶と水路破損を知る → 話を聞く |
| 8〜10話 | 一人で直せない理由を理解する → 練習 → 安全を守り協力 → 村に水が届く → おてが握手になる |
