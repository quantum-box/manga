# 転生したら柴犬だった。

[第1〜30話を続けて読む](webtoon-v5/all.html) · [話一覧](webtoon-v5/chapters.html) · [採用版の制作資料](webtoon-v5/README.md)

各話が短かったため、全10話を各10枚・約40コマ、計100枚へ作り直した。続編の第11〜30話を加え、採用作画は計300枚。村の水路の修復、役割と休息、握手を断っても仲間でいられる関係まで描く。犬の身体と声への戸惑い、子供の救助、同行する選択、旅と狼、魔王との対話、失敗と練習を描き、最後の「おて」が信頼の握手になる。日本語の縦書き会話は絵と一体のラスター画像。

旧版はGitの履歴で管理する。採用作画に使う[ポチ](references/pochis-color-sheet.png)、[姫](references/02-princess.png)、[魔王](references/03-demon-king.png)の共通参照は保持する。
