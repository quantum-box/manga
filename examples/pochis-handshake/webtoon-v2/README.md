# 柴犬ポチ×異世界転生 Webtoon v2

[スマートフォン縦読みプレビュー](index.html)。

調査ノートの9ビートを維持し、12枚のコマ画像へ分けました。肉球、ポチの驚き、姫の依頼、首をかしげる返事、魔王の足元と顔、「おて」、魔王の反応、肉球と籠手の接触、握手の引きが順に流れます。魔王の足元から顔へ進む間と、「おて。」から返事までの沈黙を長いコマ間で作っています。

## 編集

- セリフ、吹き出しの位置、コマ幅、コマ間のピクセル値、スクロール何画面分空けるかは [episode.json](episode.json) で編集できます。
- 画像は panels フォルダ内のPNGです。セリフや吹き出しは画像に描き込んでいません。
- JSONを編集したら、リポジトリのルートで次を実行して [index.html](index.html) を更新します。

<code>python3 examples/pochis-handshake/webtoon-v2/build.py</code>

生成済みHTMLは画像データを相対参照する静的ページです。ブラウザで index.html を直接開けます。スマートフォン幅のプレビューでは画面を縦にスクロールしてください。

## 参照と生成

- ポチの配色・首飾り・星のチャーム、姫の青白いドレスとティアラ、魔王の角・黒髪・紫の鎧は、既存のカラー参照シートとカラー試作に合わせた指示で描きました。
- 画像は組み込み image_gen でコマごとに生成しました。外部APIキーは使っていません。
- 各コマの生成指示は [PROMPTS.md](PROMPTS.md) に記録しています。
- 既存の試作は変更していません。

5. 魔王を足元から顔まで見せる — 07、08
6. ポチが前脚を出して「おて。」 — 09
7. 魔王の目と手が変わる — 10
8. 肉球と籠手が触れる — 11
9. 姫が驚く握手の引きとオチ — 12
