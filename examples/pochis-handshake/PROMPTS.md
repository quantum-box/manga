# Built-in image generation prompts

## 1. Character sheet

```text
Use case: illustration-story. Asset type: character reference sheet for an original Japanese black-and-white fantasy manga. Create one distinctive protagonist only: a compact, cheerful male Shiba Inu dog named Pochi, warm cream muzzle and belly indicated by white negative space, dark brow spots, curled tail, triangular ears, short paws, expressive round eyes, wearing a simple small neckerchief with a star charm. Show the SAME dog in four clean reference views on a white background: front, three-quarter, side, and an expressive happy pose. Professional manga ink line art, clean silhouettes, moderate screentone, consistent anatomy and markings. No words, no labels, no captions, no border, no watermark. This is an original character design, not any existing franchise.
```

## 2. Four-panel page

The character sheet was supplied as the reference image.

```text
Use case: illustration-story. Asset type: finished one-page Japanese 4-panel manga. Input image: character reference sheet of Pochi, the SAME Shiba Inu in all four panels. Make a polished original black-and-white manga page, portrait 2x3 aspect, four clearly separated rectangular panels in a strict 2x2 grid, wide white gutters, strong reading flow from top-right to top-left to bottom-right to bottom-left. Recurring Shiba Pochi must keep identical dark coat, white muzzle and eyebrow spots, curled tail, neckerchief and star charm from reference. Story: TOP RIGHT: Pochi sniffing a glowing stone during an ordinary walk, suddenly drawn into a magical portal; surprised expression. TOP LEFT: inside a fantasy throne room, a kind princess kneels and welcomes the small dog as the summoned hero; huge castle columns. BOTTOM RIGHT: on a windy battlefield, an intimidating horned demon king towers over tiny Pochi, but Pochi calmly raises one front paw as if asking for a handshake. BOTTOM LEFT: punchline, demon king kneels and gently shakes Pochi's paw, both smiling, the princess watches in stunned relief, peaceful sparkle. Comic timing, expressive faces, coherent character and outfits, bold manga ink and subtle screentone. Keep generous clean white areas in each panel for later speech balloons. No lettering anywhere: absolutely no words, no Japanese glyphs, no sound effects, no numbers, no captions, no speech balloons, no watermark. Do not add extra panels or characters. Prioritize visual storytelling and accurate repeated character design.
```

## 3. Lettering

The four-panel page was supplied as the edit target.

```text
Use case: illustration-story. Edit target: the immediately preceding black-and-white four-panel manga page. Preserve its four panel art, characters, layout, reading order, and drawing style exactly. Add only minimal clean white manga speech balloons or caption boxes in areas that do not cover faces or the important paw handshake. Letter the following Japanese text accurately, exactly as written, with no other text: TOP LEFT princess balloon: 「勇者さま、魔王を倒して！」. BOTTOM RIGHT small balloon from the Shiba Inu: 「おて。」. BOTTOM LEFT bottom caption box: 「魔王が仲間になった！」. Keep upper right first panel without text. Use bold, crisp, legible Japanese manga lettering. No additions or changes to the art, no extra characters, no watermark. This is a precise lettering edit; preserve every scene and especially the same Shiba's neckerchief and star charm.
```

## 4. Reincarnation caption

The lettered page was supplied as the edit target. This draft produced an incorrect first kanji and was not selected.

```text
Use case: illustration-story. Precise text-only edit of the immediately preceding finished Japanese four-panel manga page. Preserve absolutely all existing artwork, panel borders, characters, and the three existing Japanese texts exactly as they are. In the TOP RIGHT FIRST PANEL only, add a small rectangular white manga narration box in the clear upper-right sky area, with exactly this Japanese text: 「転生したら柴犬だった。」. The box must not hide Pochi's face, the glowing portal, or the crystal. Do not change or add anything else. Keep all Japanese glyphs crisp and correct. No watermark.
```

## 5. Caption correction

The preceding draft was supplied as the edit target. This is the prompt that produced the final page.

```text
Use case: text-localization. Edit the immediately preceding manga page. Correct ONLY the text in the small white rectangular narration box in the TOP RIGHT panel. It must read exactly 「転生したら柴犬だった。」. The first two kanji must be 転生 (reincarnation), not any similar-looking characters. For accuracy, render the narration as two horizontal lines: line 1 「転生したら」 and line 2 「柴犬だった。」. Preserve absolutely every other pixel, panel, art detail, balloon, and the other three Japanese texts unchanged. No new text.
```
