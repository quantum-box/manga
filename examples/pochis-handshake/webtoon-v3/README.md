第1話「ポチと魔王の『おて』」。Webtoonスキルで全10場面を新規作画。転生への戸惑い、姫の恐怖を見て助ける選択、魔王の孤独への気づき、肉球を差し出す理由をつなげた。声と足元の後で魔王の顔を見せ、おての後は長い静けさを置いた。

組み込みimage_genで絵・吹き出し・正立した縦書き日本語を一体生成。HTMLには台詞を重ねない。旧版と原本は保持する。原本・生成元・SHA-256はprovenance.json、表示確認はvalidation.jsonに記録する。画像内の文字は画像生成で編集し、余白はreader.cssとindex.htmlで編集する。

390×844と360×800で最後まで確認する。iOS同梱版は同期スクリプトで更新する。実機と公開サーバーの反映は別の確認対象。
