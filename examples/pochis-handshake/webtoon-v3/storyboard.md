# 転生したら柴犬だった。 — Webtoon v3

第1話「ポチと魔王の『おて』」。全10場面。転生の理解→頼まれる→怖さを共有する→助ける選択→魔王の孤独に気づく→肉球を差し出す→交流と安堵。

会話・内心は原画内に一体生成する縦書き。ポチは日本語で内心を語るが、声は最後の「ワン！」だけ。おては思考と動作で伝える。
