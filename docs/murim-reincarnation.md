転生は新しい身体・身分・時代で生きる仕組み。回帰は過去へ戻ってやり直す仕組み。武侠は門派、師弟、武術、江湖の関係を物語の中心にするジャンル。組み合わせは似ていても同義ではない。

## 採用したオリジナル企画

『剣聖、仇の弟子に転生する』。かつての剣聖が弱い少年として目覚めると、自分を殺した男の弟子になっている。復讐したい相手が自分を庇い、「今度こそ、お前を死なせない」と告げる。

第1話は世界の説明を詰め込まず、死 → 弱い身体への気付き → 声と石段 → 仇の顔 → 過去の剣技 → 救出 → 師匠の言葉、の7場面で進める。過去の達人・身体の弱さ・師弟の謎を、絵と行動から理解できるようにした。

作品名・人物・門派・事件はオリジナル。参考作品の場面やデザインを再現せず、ジャンルの約束と読者が続きを見たくなる仕組みを研究した。
