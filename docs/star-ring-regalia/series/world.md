# 世界観・魔法・技術・ゲームのルール

本資料は作者向けの仮設定。[企画の入口](bible.md)にあるユーザー指定条件と、ここで追加した提案を区別する。ゲーム運営会社・学校・事件・科学技術は架空。日本の地名は実在する場所を使い、具体的な施設・通学経路は脚本化時に確認する。

## 世界の核

エルセリアは、巨大な光の環「星環」が空を横切る、独立した実在世界。環は夜の時間とともに傾いて見え、場所によって空の切り取り方が違う。精霊と魔法は地球との接続以前から存在する。星環の全てを機械と説明せず、自然の魔力循環と、そこに後世の人々が作った設備を分ける。

日本で販売されるVRゲーム《REGALIA》は、接続技術によってこの世界の身体を遠隔操作し、視覚・聴覚・触覚を受け取るサービス。現地を生成するソフトウェアではない。地球側から変更できるのは、アバターへの入力と利用できる機能、翻訳、HUD、報酬表示、接続先の許可。地形、過去、現地の心を直接編集する権限はない。

| カルダ鉄邦 | 山を削らず岩壁に橋を架けた鍛冶都市、炉の赤い光、魔導列車。人間と長命の鍛冶種族が一緒に働く | 工房と労働組合の評議会。輸送で食糧を得るため、辺境への再配分を単純には支持できない |
| リュシア諸島 | 崖に沿う白い港、潮に合わせた市場、海中の精霊の光、龍の背を遠くに見る航路 | 港の自治と商会の競合。保険・航路情報・接続部品の輸送を握る商会の中でも利害が分かれる |

| 北天・竜の回廊 | 竜の移動に合わせる航路、浮島の草原、かつての巨人の階段、環の影に浮かぶ夜の都市 | 都市国家と移動民の交渉。聖王国に「魔王領」と呼ばれる一部は旧協定から排除された自治領 |

ミルトから鉄邦までは荷車と船で約4日、鉄邦から諸島の玄関港まで列車と船で約6日。王都へは通常航路でさらに約8日。北天へは竜の季節に合わせる必要があり、出発日を選べない。転送は認可された二つの拠点の間だけで、身体と荷物には大きな消費がかかる。長距離の旅には、輸送費・食事・天気・宿と出会いが残る。

竜は災害を起こす個体も、人と契約して航路を開く個体もいる。精霊は燃料や説明用の端末ではなく、その土地に欲求と行動を持つ存在。知識の違う種族はいるが、一つの種族を単一の政治的意見に揃えない。

## 魔法の五つの制約

| 項目 | 作者が固定するルール | 生活・戦いへの結果 |
| --- | --- | --- |
| 発動 | 身体で魔力を取り込み、習得した形と意図を合わせる。訓練と環境の観察が必要 | 「知っている呪文」を唱えるだけでは使えない。航にも失敗と教師が必要 |
| 供給 | 地域の循環から有限の流量を使う。回復には季節、土壌、水、時間が関わる | 大軍の復活や巨大装置の連続使用は、同じ水系の町の生活を圧迫する |
| 代償 | 発動者の疲労、装置の発熱、循環の減耗。過負荷は身体と部品を傷める | 使い切った力を覚悟だけで無限に補充しない。休養・補修・補給が必要 |
| できないこと | 死んだ現地の人を生き返らせる、記憶を任意に巻き戻す、人格を直接書き換える | 失った命と関係を「更新」でなかったことにできない。通信と心の読み取りを区別する |
| 対抗と失敗 | 型を乱す、媒体を壊す、供給を断つ。違う条件で使えば意図と違う結果になる | 剣で近づき、術式の起点や動きを止める戦いが成立する。万能の無効化能力は置かない |

魔法には熱・風・水などを扱う技術のほか、精霊との交渉で可能になる働きもある。精霊の契約は口約束で終わらず、相手に守らせる義務と自分が引き受ける義務を伴う。後半で新しい契約が現れても、相手の意志と既存の限界は消えない。

## テクノロジーの余地

魔導器は、職人が一定の魔法の型を刻み、繰り返し使えるようにした道具。魔導列車、冷蔵箱、通信器、装具がある。魔法使いの工夫を全て再現できるわけではなく、用途・部品・充填の条件が固定される。

日本側は通信の解析、表示、翻訳、複数人の連携に強い。現地は媒体の素材、精霊との交渉、魔力の流量、身体への影響を知っている。合同の開発には、説明の食い違い、試験、失敗と修正を描く。航自身は剣道経験のある高校生で、工学の天才ではない。

銃に相当する投射武器と砲も存在する。守備兵は盾、装甲、風の魔法で対抗するが、弾を必ず防げるわけではない。射線の通らない遺構、細かい術式への接近、盾で距離を詰める連携などを用意し、剣が全ての状況で最適だとは言わない。飛行船や鉄道があるのに、軍だけ技術を知らない不自然さを避ける。

普及の限界は、媒体の希少さ、交換部品、保守できる職人、土地ごとの精霊の許可。高い技術がある場所とない場所の違いが、価格、職業、移動、政治を変える。

## アバター・ログアウト・復活

| 項目 | 一貫した仕様 |
| --- | --- |
| 身体 | 認可された接続拠点が魔力を用いて構成した実体。初回生成、活動、補修、再生成で有限の魔力を使う。プレイヤーの意思と記憶は日本側の本人にある |
| ログアウト | 任意に切断できる。安全な拠点では身体を保管。危険地で切断すると身体は動かなくなり、味方に運搬などの負担が残る。帰還不能は基本の危機にしない |
| 日本の本人 | ゲーム内の身体が死んでも本人は死なない。痛覚は制限され、身体の破壊を検出すると接続を切る。ただし恐怖、罪悪感、睡眠不足、日常での問題は残る |
| 再生成 | 申請と供給が許されれば、拠点に新しい身体を作れる。武器、荷物、他人との約束、壊したものは戻らない。消費は他の生活設備と同じ配分に計上される |
| 現地の人 | その身体で育ち、記憶を形成した人。遠隔の本人も保管された元データも存在しないため、プレイヤーと同じ復活の仕組みは使えない |
| 時間 | 日本とエルセリアは同じ速度で進む。更新・メンテナンス中も現地の人は暮らし続ける。都合よく何年も経過させない |
| 通信 | 双方向の音・映像・入力は通せる。情報の意味は翻訳装置を介す。誤訳、距離による中継、権限での遮断がある。常に全員の居場所や心を見られるわけではない |
| 物と人の越境 | 現行の接続は情報の往復だけ。日本へ剣や現地の身体を持ち帰れない。終盤でも突然、物理的な門を開いて避難できない |

敵もこれらの仕様を理解して動く。プレイヤーの戦闘不能は時間と補給の損失だが、現地の兵の戦死はその人の生涯の終わり。アウレルが帰還者を優先して軍に採用する理由になる。同時に、何度も生成できる兵力が魔力循環を削るという弱点を持つ。

## 初回接続の演出（2026-10-10ネーム採用）

第1話では、初回の歓迎、プレイヤー名「コウ」の選択、手指の開閉に身体が応える体験、本人が世界へ進む選択を短い案内として加える。光片と大きな光流は接続中の主観的な映像表現であり、日本の部屋を壊したり身体を物理的に越境させたりするものではない。身体の生成や運営の真相は初回案内では説明しない。到着後は草、花、風、水、星環、竜、川沿いの暮らしを見せ、冒険したくなる美しさを先に育てる。

## ゲーム表示と支配の構造

一般に見えているゲーム表示は、現地から届く依頼と地球側の分類を合成する。聖王国は接続許可を与える代わりに、通行先・目標・報酬の条件を指定する。運営はその依頼をイベントへ加工する。この関係は、現地の地形を直接編集する能力とは別物。

「NPC」は地球側の分類。「帰還者」は現地の人がプレイヤーを呼ぶ言葉。最初は同じ存在を言い換えているだけに見えるが、現地が外来者の反復到来を政治と暮らしの問題として扱ってきたことが分かる。

討伐対象の肩書と敵の意図は分ける。序盤の黒冠の守護者は水源設備を守る古い自律兵器で、侵入者を攻撃する危険な相手ではある。王国は上流の保護区を開くため、討伐を「汚染を止めるイベント」と説明する。倒すと中枢の分流弁が常時開き、首都側への取水が増える。下流のミルトは必要な流量を失う。守護者を元通りに再生成する手段はなく、地域の人々と新しい弁を作り、配分を交渉する必要がある。

## 接続の歴史と作者が知る真相

| 時期 | 確定する出来事 |
| --- | --- |
| 約700年前 | エルセリアの複数地域が循環を分け合う旧協定を結ぶ。星環と交信する観測装置が作られる。神話の全てを実装仕様へ還元しない |
| 約80年前 | 戦争と流路の変更を経て王都への優先供給が制度化。「魔王領」とされた北天の自治領が管理から排除される |
| 12年前 | 地球の研究班が異常な通信に応答し、エルセリアの観測装置と情報を往復できる架橋器を作る。身体の遠隔操作と感覚伝達は架空の接続技術である |
| 3年前 | 架空企業オルビス・リンクが《REGALIA》を公開。最初の研究班と経営の一部は実在世界だと知る。通常の開発部門へは外部生成環境として説明される |
| 物語開始時 | 利用者拡大と次期大規模イベントの準備が、魔力の回復速度を超え始める。聖王国は保護区を開くため守護者の討伐を発注する |

運営が秘密を守る理由は、サービスの成立過程を隠し、接続契約と独占を維持するため。全社員を共犯にしない。知らなかった技術者にも、事実を知ってから選べる行動と責任を与える。

実在を確認する場面では、開発資料だけを読む推理で終わらせない。創設時の研究記録、架橋器をゲーム処理から分離する試験、現地で協力者が実施する通信実験を組み合わせる。具体的な試験演出は第31〜60話の脚本化時に固定し、現時点では測定値や実験結果を作ったことにしない。

## 日本の日常

舞台は数年先の埼玉県川口市と東京。これは実在の日本を土台に、VR接続技術だけを追加した架空の近未来。現代日本でこの技術が実用化しているという説明はしない。

航の家は小さな弁当店。豪華な生活ではないが、家族が全員不幸という出発点にもしない。主人公の傷は「現実で誰にも役立てないと思い込んでいること」であり、家族を殺すために事故を置かない。手伝い、翌日の学校、部活、受験・就職の準備が戻る理由と生活の制約になる。

航が町で行った約束は、日本の約束とぶつかる。断らず全部を抱えれば学校にも町にも迷惑がかかる。代役を頼む、予定を伝える、待ってもらうことを、弱さではなく主人公の成長として描く。
