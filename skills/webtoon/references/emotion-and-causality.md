# 主人公の感情と行動の因果

新作の構成、読者が主人公に共感できない場面、展開が速すぎる場面の改稿で使う。2026-10-05の『天魔、二周目。』第1話を実例にする。ユーザーは、主人公の戸惑いを描かないと共感できず、速い展開に読者が置いていかれると指摘した。修正後は、システム表示の追加修正を含め「まあ一旦ok」と暫定採用された。

同梱の[修正前の全長](ngplus/full-before.jpg)と[現行の全長](ngplus/full-after.jpg)は構成の比較に使う。顔と文字は下記のスマホ幅の画面を表示して確認する。[絵コンテ](ngplus/storyboard.md)に各場面の情報、行動、間の目的がある。これらは参考資料で、新作へ貼る素材や固定の物語ではない。

## 能力と本人の理解を分ける

この実例は、ゲームをやり込んだ学生が処刑直前の雑役弟子へ転生し、LV.999のセーブデータを引き継ぐ話。能力があること、身体が動くこと、その人が安心して使えることは別々に進む。

| 段階 | 読者と主人公が知ること | 感情や身体の証拠 |
| --- | --- | --- |
| 危機 | 知らない名前で呼ばれ、縛られている | 縄の痛み、石の冷たさ、聞いてもらえない恐怖 |
| 失った日常 | 昨日までは授業とゲームだけの暮らし | 夢だと疑い、目を閉じても痛みが残る。帰りたいと願う |
| 新しい力 | 表示に自分のセーブがある | すぐ納得せず、指先で縄を切って確かめる |
| 成功 | 刃を二本の指で止めた | 本人も驚き、指の痛みを確かめ、やめてほしいと頼む |
| 結果と目的 | 押し返すだけで敵が飛ぶ | 生存を確かめ、手の震えと安堵を経て「生きて帰る」を選ぶ |

新作では性格と状況に合う反応を選ぶ。全主人公へ恐怖、涙、普通の学生という属性を強制しない。強い主人公の快感を求められても、本人の動機や選択を省略しない。

## 共感の接点を絵で残す

[恐怖の画面](ngplus/fear-390.jpg)、[力を試す画面](ngplus/strength-390.jpg)、[剣を止めた反応](ngplus/catch-390.jpg)、[戦闘後の手と顔](ngplus/aftershock-390.jpg)を見比べる。

「戸惑っている」と説明する文章だけを増やすと、表情が不敵なまま残ることがある。眉、瞳、口、視線、手の緊張、姿勢を、セリフと同じ感情へ編集する。相手を心配しているなら、目線と間もそこへ向ける。汗や涙は感情に合う量を使う。

この改稿では表情を3枚編集し、再攻撃・防御と戦闘後の反応を2枚追加した。使える作画は保ち、欠けた情報の箇所だけを描き直した。[当時の生成指示](ngplus/emotion-prompts.md)は編集対象、不変条件、顔や手で見せる反応の参考になる。

## 行動の理由を絵でもつなぐ

[再攻撃と防御](ngplus/defense-390.jpg)は、剣の破砕から掌打への飛躍を埋めた画面。長老が剣を失っても拳で突進することを見せ、主人公が身を守るため左掌を出したことをつなげた。

改稿では次の三つを確認する。

1. 行動のきっかけが直前の絵や発話にある。
2. 手、武器、距離、受ける身体の向きが、結果とつながる。
3. 行動後の本人の反応が、その人の意図と実際の結果を伝える。

この例では右手で刃を止めて砕き、左掌で防御する。縄は切れた後に拘束へ戻らず、壊れた剣は復活しない。こうした状態を絵コンテに残す。

## 速さの改稿は、欠けた理解から始める

短い動作は密に置き、理解や結果を受け止める箇所で速度を落とす。大きな空白だけを追加しても、場面を省略した因果は補えない。前の出来事を整理できないうちに、次の事件や固有名詞が重なっていないか確認する。

この改稿では山場を長老との一戦へ絞った。本人の生還を描いた後に周囲の驚きと報酬を置き、報酬にも実感が追いつかない反応を残した。天魔剣の姿、臣従、隠しルートは次話へ送り、第1話では禁庫の音だけを引きにした。[終わり方](ngplus/ending-390.jpg)では、一つの目的を本人が選んでから謎へ進む。

一話一戦、音だけの引き、長い無言の間は今回の選択。新作では感情を処理する量と話の目的から山場や引きを決める。

## 見せ順と感情を別々に確かめる

「止まってくれ」という祈りの下端から、指で刃を止める絵の見え始めまでを測った。390×844 CSS pxでは971.6px、360×800では898.4px。この表示範囲では、祈りと結果を同時に見せない距離を確保した。

この数値は最低余白ではない。距離を満たした後も、スクロールしながら、本人の疑いから成功への驚きがつながるか、結果を受け止める前に報酬へ飛んでいないかを読む。全長が増えただけで、感情の改稿が成功したとは判断しない。

現行の完成画像は390×17,945px、DOM全長は17,946px。作画10種類を17の表示窓で使い、生成文字・表示9点と合わせて画像の表示は26箇所。枚数や全長は今回の制作記録であり、作品の目標値ではない。

この実例は既存の横書きHTML会話を保って部分改稿した。新作の日本語会話では、スキル本体の縦書き・吹き出し込み生成を既定として使う。
