# 採用された実例：人物を描かない余白

2026-10-07、『ゼロブレイク』の装着シーンの部分試作を、ユーザーが「あ、そうそう！上手くできてる 例とかskillに入れといたら？」と評価した。これは余白と情報の見せ順の採用例。正式な第1話の置き換えや、第2〜10話全体の承認には広げない。

同梱の [390px完成画像](zero-break/whitespace/complete-390.png) と [360px完成画像](zero-break/whitespace/complete-360.png) を画像表示ツールで見る。全長の縮小表示では密度の配置を、下の画面窓では文字と出現順を見る。画像はスキル内にあり、元の作業場所や生成キャッシュがなくても参照できる。

## 何を待たせたか

| 区間 | 余白に置くもの | 次に残した情報 |
| --- | --- | --- |
| 起動・手首 | 胸から腕へ走る光、裸の手首の格子を近くで読む | 完成した全身 |
| 固定の音 | 白地に「カチッ」だけ。直前の手首と因果をつなぐ | 固定後の姿 |
| 接続の通知 | 縦書きの「接続完了。」だけ。枠・人物・尾は描かない | 主人公の姿と反応 |
| 出現前 | 細いシアンの光だけを下へ流し、白へ消す | 人物の輪郭も全身も出さない |
| 完成披露 | 黒い装甲と赤いマフラーの全身を大きく見せる | ここで止まって受け止める |

密な作動を読んだあと、絵がなくても音や言葉で出来事を追える区間へ移り、光をたどった先に全身を置いた。音、通知、光を一枚の漫画ページへ詰めず、独立した疎な原画と異なる長さの間を組み合わせている。

「接続完了。」はシステム通知であり、レンの発話や心の声ではない。セリフだけの余白へ応用するときは、その言葉の話者・声の種類・前後のつながりを決める。文字を常にシアンにする、尾を常に省くという基準にはしない。

白地、装甲、5区間、全長、距離はこの場面の選択。毎回すべての種類を使う、空白を同じ高さにする、全身を必ず一画面以上遅らせる、といった固定の構成へ変えない。

## 記録した距離と確認範囲

| ネイティブ画面窓 | 完成画像の全長 | 通知の文字下端→全身原画の上端 |
| --- | ---: | ---: |
| 390×844px | 3385px | 939.67px |
| 360×800px | 3124px | 867.31px |

距離は原画の文字の色領域と組版位置から計算した。全身原画の上端を使うため、髪や装甲が見える位置より手前で測る保守的な値。DOM実測やブラウザのフォント値ではない。原画5枚と360/390px幅の連続窓12枚で、文字、手、衣服、余白内の情報、全身の先出しがないことを目視した。ユーザーは提示した画像の演出を採用した。ブラウザの実スクロールと実機は未確認であり、画像の採用と区別する。

## 制作と出所

既存の起動・全身原画2枚を無加工で使い、音だけ・通知だけ・光だけの原画3枚を組み込み `image_gen` で新規生成した。文字は原画内に含まれ、HTMLでは再掲していない。[実行した3つの作画指示](zero-break/whitespace/prompts.txt) と [採用・出所・同梱画像のハッシュ](zero-break/whitespace/example.json) を参照する。

元の成果物は `quantum-box/manga` の `examples/zero-break/production/scroll-pacing-sample/`、試作のコミットは `1490fe8bfc4a8149f91a53915051d5d84f419250`。スキルには参照に必要な完成画像・画面窓・指示を収録し、作品の全素材やリーダーを複製する必要はない。
