# コマと余白を跨ぐ音

音の持続、広がり、距離を縦スクロールで体感させるときに読む。効果音は発生したコマの中だけへ収めず、複数コマと余白へ続ける演出を積極的に候補へ入れる。動作ごとの短い音や静かな判断と組み合わせ、その音が始まり、続き、終わる理由を決める。

## 一つの音の時間と範囲を描く

| 意図 | 音の配置 | 終わる位置 |
| --- | --- | --- |
| 見えない大きなものが動く | 小さな前兆から反応のコマへ続き、余白へ伸ばす | 発生源の大きな姿を下で見せる直前 |
| 重い衝撃が響く | 字の一部を枠の外へ出し、コマ間や次のコマの空いた背景まで響かせる | 次の通知や静かな判断を読む前 |
| 近づく・離れる・広い場所へ届く | 字の間隔、強さ、位置、振動線や薄れ方で距離を作る | 発生源が止まる、離れる、聞く人物が変わる位置 |
| 返事を受け止める・決断する | 必要なら残響を終えて、文字も音もない間を置く | 次の意図した動作や発話が始まる位置 |

音源、正確な全文、始まるコマ、跨ぐ境界、余白の用途、減衰と終了位置を絵コンテに記録する。持続する轟音を、独立した衝撃が何度も起きたように数えない。同じ全文を各コマへ複製せず、一続きの字形・反復・残響として扱う。連打や複数の足音を描くなら、それぞれの接触が本当に起きていることを前後の動作で示す。

顔、目、手、武器、吹き出し、ゲーム窓を避けた通り道を確保する。字が枠を越えても、読順は保ち、画面端で欠けさせない。大きな字は構図と一緒に設計し、既存の狭いコマへ後から押し込まない。全部の音を大きくしたり、全ての余白を文字で埋めたりせず、小さな接触音と音のない間で強弱を作る。

## 余白を音が届く時間にする

人物や背景を描かない余白にも、効果音とその減衰だけを置ける。姿より先に音を届ければ、次のスクロールで発生源を探す流れになる。逆に衝撃の後へ残響を伸ばせば、画面が変わっても同じ出来事を感じられる。

既存の空白の一部を音のある原画内へ移す場合、原画の白い部分とHTML等のコマ間を足した実際の待ち時間を確認する。画像外へ余白を足すだけで、画像内に焼き込まれた問いと答えの見せ順が変わったと扱わない。白地、下へ伸びる字、長さ、縦横比は今回の選択。別作品では背景色と音の性質へ合わせる。

## 発生音と継続音を別に記録する

無言は発話がないこと、無音は効果音もないこと。後続コマで新しい音が発生しなくても、前のコマの音が続く場合は無音と指定しない。共通の `silent / no text / Sound effects: none` が持続音を消していないか確認する。

制作データは、たとえば発生側を `sounds`、後続側を `sound_continuations` として分けられる。

```json
{
  "moment": "B",
  "dialogue": [],
  "sounds": [],
  "sound_continuations": [
    {
      "origin": "A",
      "text": "ゴゴゴゴ…",
      "placement": "前の接写から反応の外側を通り、下の白い余白で減衰する"
    }
  ]
}
```

これは必須のデータ形式ではない。後続コマの指示では「前からの同じ音を継続」「新しい音や全文の複製を追加しない」と明示する。音の件数は発生側で数え、継続先へ同じ音を二重計上しない。発話・HUD・発生音・継続音はそれぞれ独立させる。

生成指示の要点:

```text
One continuing inscription, exact text: [full sound].
It begins in [moment A], extends beyond its panel frame, crosses [gutter],
and continues into the empty edge of [moment B].
This is the SAME sound persisting, not a new impact or duplicate complete word.
Keep it off faces, hands, dialogue and HUD.
Let it decay through [white/background space] and end before [quiet beat].
Do not reveal [withheld subject] until the following image.
```
