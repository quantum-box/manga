# 『帰還』一話ネーム設計

この資料は、ユーザー採用前に構成・感情の因果・縦読みの間を確認するための一話全体のネーム設計である。本作画の完成稿ではない。画像生成時は [sequence-plan.json](sequence-plan.json) の各 `sceneDescription` を使い、1パネルにつき独立したラフ絵を用意し、8カットを1シートへまとめてよい。

## 一話の核

ライトボブの治療係ミナは白い仕事着、短髪で暗髪の兵士レンは暗い服を着る。レンの右前腕には川での救助中に負った傷がある。ミナは帰還を待っていた心配を冷たい敬語に隠し、レンは心配を増やさないため平気なふりをする。

雨の接近を最初に置き、レンが川で流されかけた少年を救い、岸の匿名村人へ渡して安全を確認したため遅れたことを短い回想で理解させる。ミナは救助の場におらず、現在へ戻って初めて事情を聞く。手当てを始めたところで雨漏りと天幕の支柱の不調が治療を中断する。レンは右腕をかばいながら無理に直そうとするが、ミナが左手で担える役割を渡す。二人で天幕を支え、レンは助けを受け入れる。

その後の手当てで、ミナは「本当は怖かったですか」と問い、レンは戻れないと思った恐怖を、ミナは待つことの怖さを返す。ミナが包帯を結びながら抽象的な約束を具体的な時刻・道・一個の木札へ変え、レンは一週間後の次の巡回で木札を帯に携帯し、予定内に入口のフックへ掛ける。木の「コト」音を合図に、最後は「確認しました」「次も戻る」で冷たい形式の内側に信頼を残し、次の巡回へ接続する。

## 10シートの役割とテンポ

| シート | カット | 局面 | 役割とテンポ |
|---|---:|---|---|
| 01 雨を待つ天幕 | p01–p08 | `entrance` | 遠雷・風・空いた道を広めに置く。足音、挨拶、血の一滴へ順に狭め、帰還の安堵より傷の不安を先にする。 |
| 02 遅れた理由 | p09–p16 | `entrance` | 強がりの説明、泥の手、レンの救助、暗い袖の匿名村人への引き渡し、現在への帰還を分ける。回想は原因理解のためだけに使い、現在の治療へ戻す。 |
| 03 手当ての距離 | p17–p24 | `development` | 座る、腕を差し出す、水を注ぐ、痛がる、強がる、滴を見るという新しい動作を重ねる。最後に治療を止める異変を置く。 |
| 04 支柱が倒れる | p25–p32 | `development` | 雨漏りから包帯、結び目、支柱へ視線を移す。レンの無理をミナが止め、負傷側を使わない役割が成立する。 |
| 05 待たせたくない | p33–p40 | `development` | 同じロープを持つ作業中に、転倒、心配、待っていた事実、レンの本音を別の反応として置く。p40後は告白を読む深い間。 |
| 06 二人で持つ | p41–p48 | `development` | 告白を受けた沈黙、役割の再確認、傷の悪化、原因の共有、助けを借りる決断を積む。修復が済んだ結果として治療を再開する。 |
| 07 平気のふりの返し | p49–p56 | `climax` | 痛い、本当は怖かったのか、戻れない恐怖、待つ恐怖を往復させる。p54の聞き手の反応を独立させ、p55でミナの敬語を一度崩す。 |
| 08 包帯を結ぶ | p57–p64 | `climax` | 痛いと言えば崩れそうだった本音、頼る、時刻を決める、一個の木札を選ぶ、帯へ携帯する準備を置く。帰還時の木の音は先取りしない。 |
| 09 待つ側の手を動かす | p65–p72 | `result` | 水の流れ、乾布、休息、道の確認、帯の木札から空の入口フックへ掛ける手順の確認、飲み物で危機後の身体と関係を回復させる。次の帰還を迎えられる状態を作る。 |
| 10 戻ったという行動 | p73–p80 | `satisfaction` | 一週間後の晴れた朝の出発、ミナの準備、同日夕方に帯の木札を入口フックへ掛ける木の音、迎えに出る反応、時間内の帰還を順に描く。最後の短い交換で満足と次回の入口を残す。 |

各シートは4列×2段、各段は右から左に読む。`sequence-plan.json` の `readingIndex` がシート内の読み順であり、カット数を画像ソースの枚数やコマ枠の反復で水増ししない。p13–p14はレンと少年の救助、p15は暗い袖の匿名村人の手へ少年を渡すカットで、ミナは回想の救助場面に出さない。主役の連続性は現在のミナとレンの二人に保つ。

## 5局面IDと因果

- `entrance`（p01–p16 / group-01–02）: 雨の予告 → 待つミナ → 遅れて戻るレン → 右前腕の傷 → レンが少年を匿名村人へ渡して安全を確認した救助という理由。
- `development`（p17–p48 / group-03–06）: 手当て開始 → 強がりの矛盾 → 雨漏り → 支柱の不調 → 役割分担 → 待たせたくなかったという本音 → 助けを借りる決断。
- `climax`（p49–p64 / group-07–08）: 痛みを言う → 本当は怖かったのかと問う → 戻れない恐怖 → 待つ恐怖 → 謝罪 → 時刻・道の具体化 → 一個の木札を帯へ携帯する準備。
- `result`（p65–p72 / group-09）: 天幕が持ち直す → 乾布を準備する → レンが休む → 巡回路と木札の手順を確認する → 次の帰還を支える準備が揃う。
- `satisfaction`（p73–p80 / group-10）: 一週間後の晴れた朝に出発 → ミナが作業へ戻る → 同日夕方に帯の木札が入口フックへ掛かり「コト」と鳴る → ミナが迎えに出る → レンが予定内に戻る → 次も同じ手順を続ける。

重要な台詞は、言った人の意図だけで終わらせない。`sequence-plan.json` の `reaction` は聞き手・相手の表情、手、姿勢、次の判断を記録している。たとえば p37「あなたを待つよりましです」の後は p38–p40でレンが待っていたのかを確かめ、p39のミナの過度に正確な手つきとp40のレンの返答を並べる。p52「本当は怖かったですか」の後は p53でレンが「戻れないと思った」と直接返し、p54を挟んでp55でミナが「待つのは怖かった」と返す。p58ではレンが「痛いと言ったら崩れそうで」と隠した理由を明かす。これで会話を説明の往復にせず、相手の受け取りと関係の変化にする。

## 間と純余白

通常のパネル間は、同じ場所の動作を読み取るための小さな間として設計した。`frameProposal` は計画案、最終の大小・間・節の改行・文字位置は `plan.json` に記録する。物語上の時間・感情・場面の切り替えが必要な間だけ、`auxiliaryBeats` に `pause` を置いている。各 pause には高さ、目的、直前の手掛かり、次の最初の開示、要素、背景を記録し、白さだけで長さを引き延ばさない。

- `voice-00`: p01前に「夕暮れ／野営地の治療所」と表示し、最初の時刻と場所を固定する。
- `pause-01`: 雨雲と空席を受け、ミナの手の緊張へ移る。
- `voice-12`: p12後・p13前に「少し前／村外れの川」と表示し、回想の時刻と場所を明示する。
- `voice-15`: p15後・p16前に「いま／野営地の治療所」と表示し、回想から現在へ戻す。
- `pause-02`: 泥と震える指を残し、川の回想へ入る。
- `pause-03`: 雨漏りを二人が同時に理解し、支柱を探す。
- `pause-04`: 「待たせたくなかった」の後、止まった手と視線を読む。
- `pause-05`: 「助けを借りてもいいか」「はい」の後、肩が下がる変化を味わう。
- `pause-06`: 帯に携帯された一個の木札と空の入口フックを結果の景色へ渡す。
- `voice-05`: p72後に「同じ野営地／一週間後」と明示し、急な翌朝への飛躍を防ぐ。
- `voice-06`: p76後に「同じ野営地／同日夕方」と明示し、p77の木札の帰還音へつなぐ。
- `pause-07`: 一週間後の晴れた朝から同日夕方の合図までに必要な時間を置く。

`voice` は絵から離しても読める内声・補助台詞・時間場所の目印として別管理し、描画カット数に含めない。音は、遠雷・風・足音・血滴・水・ロープ・一個の木札が帰還時に入口フックへ触れる「コト」など、動作や天候の理解を更新する箇所に限定した。木札は巡回中に帯へ携帯し、p77で入口フックへ掛かるまで鳴らさない。無音のカットには、表情・手・姿勢の反応を読む理由を `sound.noSoundReason` に記録した。

## 量の計画と確認

この段階の計画値は、有効描画カット80件、10シートである。通常一話の初期目安である幅390 CSS pxの本編高34,000–60,000、登録した純余白全体を除いた内容高24,000以上（ツール上で `.pause` だけを除いた値は部分値）を目標にするが、数値の実測は原画像・フォントを読み込んだDOMで行う。実測の正本は [validation.json](validation.json) とし、`sequence-plan.json` の `actual` はそこを参照する。計画値を実績として扱わない。

有効カットは、画角を変えただけでなく、新しい動作・理解・選択・結果・感情反応のいずれかが加わる独立描画カットとする。画像の原寸、同じ画像のcrop数、voice、pause、計測UIは有効カットにも本編内容高にも加えない。360 CSS pxでは文字・顔・手・木札・フックが読み取れ、横方向にはみ出さないことを確認する。ユーザーがこのネームを採用するまでは、本作画と公開へ進めない。

## ラフ提示時の実績

有効80コマ、幅390 CSS pxの本編高42,192.40625px。登録した純余白と内容区間高はvalidation.jsonへ記録した。量・主筋・水増しの確認はネーム提示の範囲で完了し、ユーザー採用と本作画は未実施。補助の声は「その子が助かってよかったです」「ただ戻ってほしかった」へ直し、事情の確認・条件の言い直しを減らした。
