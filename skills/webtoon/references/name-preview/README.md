# 『帰還』一話全体の構成ネーム

[80コマのHTML](index.html)を縦に読む。これは制作機能の一話全体の試作で、既存連載の採用原稿ではない。**ユーザーの構成への返答待ち**。本作画・公開へはまだ進めない。

## 構成

雨の野営地で、治療係ミナは遅れて戻る兵士レンの傷に気づく。川での救助を短い回想で見せ、手当てへ戻る。雨漏りと支柱の不調へ二人で対処し、無理を隠すレンが助けを求める。戻れない恐怖と待つ恐怖を返し合い、一週間後の巡回では木札を入口へ掛ける行動で帰還の約束を果たす。

[絵コンテ](storyboard.md)と[80コマの意図・新理解・反応](sequence-plan.json)に、入口→展開→山場→結果→満足の対応を残した。回想には「少し前」「いま」、次の巡回には「一週間後」「同日夕方」の目印がある。補助の声も、事情の言い直しから救助への安堵・戻ってほしかった本音へ直した。

## 実測

基準は幅390 CSS px、本編高34,000〜60,000px、内容区間高24,000px以上、有効80〜120コマ。予定80コマに対し、実際も80コマ。実量の正本は[validation.json](validation.json)。

| 実際の表示幅 | 本編高 | 登録した純余白 | 内容区間高 |
|---|---:|---:|---:|
| 390 CSS px | 42,192.41px | 5,379.85px | 36,812.55px |
| 360 CSS px | 38,945.84px | 4,955.70px | 33,990.14px |

UI・構成メモ・末尾の制作コメントは本編に含めない。`.pause` の4,568pxに加え、声の前後の無情報帯、p10/p77の絵の上の空白帯を登録し、重複する縦範囲は一度だけ引いた。人物の周りの白い背景は一括で余白にしない。HTMLの自動計測で表示する「明示した余白だけを除いた高」はこの内容区間高とは別の部分値。

80コマは10枚の資料にある80個の独立した出来事。画像ファイル枚数、同じ静止画の再分割、声・音・間をコマ数へ加算していない。水注ぎ→痛み、結び作業→転倒、締める→傷の再確認の3組だけを短い横並びにした。余白を追加する前の80コマ本編も39,194.41pxあり、長さの下限へ合わせるための空白追加ではない。

## 表示確認

Chromiumの390×844／360×800、倍率1で全体と150px重複の連続画面を確認した。[390px全長](review/full-390.png)・[360px全長](review/full-360.png)・[実DOMと連続画面の索引](review/browser-metrics.json)。両幅で80画像が読み込まれ、横はみ出し・JavaScriptエラーは0。セリフと声は390pxで21.06px、360pxで19.44px。DPR3、幅変更、広い画面で390pxへの収まり、計測UI開閉、画像失敗の表示も確認済み。

[救助への安堵](review/excerpt-rescue-390.png)、[待つ怖さの本音](review/excerpt-emotion-390.png)、[木札の帰還合図](review/excerpt-return-390.png)は読める画面の抜粋。31コマの吹き出しを顔と手の空きへ移し、必要な節の改行も調整した。[文字配置の記録](review/lettering-review.json)。

構成と表示の試作確認まで。実機・Safari・ユーザー採用・完成原稿・公開の合格は未確認。ラフの腕の左右、応急の布から清潔な包帯への移行、p45の出血とp77の夕方の濃淡は本作画で再確認する。

## 編集と出所

[plan.json](plan.json)が最終的な読む順、列分け、吹き出し・音の位置、コマ幅、間の正本。直したら同じHTMLへ再出力する。

```bash
python3 skills/webtoon/scripts/build_name_preview.py \
  skills/webtoon/references/name-preview/plan.json \
  --output skills/webtoon/references/name-preview/index.html --force
```

組み込み `image_gen` で人物同一性資料を参照し、8カット×10シートを生成した。各シートは1536×1024 PNGで、生成結果の原バイトをそのまま保存し、HTMLもそのバイトを内包する。セルを見せる窓はCSSのみ。原絵には文字・吹き出しを入れず、読める日本語をHTMLへ置いた。指定より鉛筆の細部とハッチングが多い出力になっている。

実行プロンプト・生成元・SHA-256は [01〜04](rough/prompts-01-04.json)、[05〜08](rough/prompts-05-08.json)、[09〜10](rough/prompts-09-10.json)。`sketches.png` は現在の10シートが参照した人物同一性・場面の資料として保持し、[元の生成記録](rough/character-reference.json)を残す。旧5カットの本文・HTML・レビュー画像はGit履歴で管理する。
