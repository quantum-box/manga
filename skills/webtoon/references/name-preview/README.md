# 『帰還』一話全体の構成ネーム

[80コマのHTML](index.html)を縦に読む。制作機能の一話全体の試作であり、**ユーザーの構成への返答待ち**。本作画・公開へはまだ進めない。

## 構成と空間

雨の野営地で治療係ミナは、遅れて戻る兵士レンの傷に気づく。川での救助を回想で見せ、手当てへ戻る。雨漏りと支柱の不調へ二人で対処し、無理を隠すレンが助けを求める。戻れない恐怖と待つ恐怖を返し合い、一週間後の巡回では木札を入口へ掛ける行動で帰還の約束を果たす。

80の独立した絵を35の場面のまとまりへ組んだ。短い返答の右→左、広い状況へ添える手元、水や結び目の横長の接写、枠なしの会話、絵の脇の声を使う。主な会話と聞き手には75〜100%幅を残し、無関係な長い空きは縮めた。35という数は今回の構成の結果であり、全話の割当ではない。

ミナの目を隠していたp47の全文は左の空きへ移した。帰還への願いはp56の左、最後の「……戻った」は帰還を見た後の間へ置いた。回想の「少し前」「いま」、巡回の「一週間後」「同日夕方」は読む順を保ち、絵で文字を隠さない。

疑問には「？」、救助や制止の強い発話には「！」を使った。疑問符7件・感嘆符5件で、静かな本音は抑えた声のまま。[記号の記録](review/punctuation-review.json)と[空間・表情の確認](review/spatial-review.json)を残す。

## 実測

幅390 CSS px、本編高34,000〜60,000px、内容区間高24,000px以上、有効80〜120コマを基準とする。今回の実際の有効コマ数は80。実量の正本は[validation.json](validation.json)。

| 実際の表示幅 | 本編高 | 登録した純余白 | 内容区間高 |
|---|---:|---:|---:|
| 390 CSS px | 35,132.27px | 5,812.41px | 29,319.86px |
| 360 CSS px | 32,429.39px | 5,358.80px | 27,070.60px |

UI・構成メモ・末尾の制作コメントは本編へ含めない。絵、吹き出し、音、声の実際の縦範囲を重ね、何もない帯を一度だけ純余白へ数える。相対配置の中の空きも含め、声の空白と絵が同じ高さにある場合は絵まで差し引かない。目視したp10上部7%の無情報帯を登録し、p77は手元の表示窓にしたため旧上部帯を登録しない。人物や演技の周りの白い背景は一括で余白へしない。

`.pause` のみを引く自動計測の値は、この内容区間高とは別の部分値。画像ファイル枚数、同じ静止画の再分割、声・音・間は有効コマへ加算しない。

## 編集と出所

[plan.json](plan.json)が最終の読む順、列分け、文字・音の位置、表示窓、場面の空間、間の正本。[絵コンテ](storyboard.md)と[80コマの意図・新理解・反応](sequence-plan.json)にも因果を残す。直したら同じHTMLへ再出力する。

```bash
python3 skills/webtoon/scripts/build_name_preview.py \
  skills/webtoon/references/name-preview/plan.json \
  --output skills/webtoon/references/name-preview/index.html --force
```

組み込み `image_gen` で人物同一性資料を参照し、8カット×10シートを生成した。各1536×1024 PNGの原バイトをそのまま保存し、HTMLも同じバイトを内包する。原画を加工せず、表示窓とHTML文字の配置を変えている。絵は指定より鉛筆の細部とハッチングが多い出力。

実行プロンプト・生成元・SHA-256は [01〜04](rough/prompts-01-04.json)、[05〜08](rough/prompts-05-08.json)、[09〜10](rough/prompts-09-10.json)。`sketches.png` は現在の10シートが参照した人物同一性・場面資料として保持し、[元の生成記録](rough/character-reference.json)を残す。旧ネームの本文・HTML・レビュー画像はGit履歴で管理する。
