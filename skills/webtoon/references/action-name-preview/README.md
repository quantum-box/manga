# 『橋上の一歩』戦闘ネーム

[プレビュー](index.html) は戦闘一場面・24コマの部分試作。既存連載の一話ではなく、一話全体の分量判定は対象外。構成は未採用で、本作画はユーザーの返答待ち。

少年剣士アキが鐘楼へ向かう石橋で門番と対峙する。槍を避ける、剣を落とす、肩の予兆を読む、低い段差で剣を拾う、跳び越えて槍を弾く、通路が開くという因果を絵でつなぐ。前半はアキ右・門番左、剣は一本でp07に落下しp16に回収、p17以後は手にある。最後は目的地の鐘楼へ進む。

## 構成を確認する資料

- [storyboard.md](storyboard.md)：動き、無音、接続の判断

- [表示確認](validation.json)：360/390px幅の実測と目視範囲

生成PNGは無加工。HTMLの表示窓で24の独立した瞬間を見せる。足元、肩、指、仮面の接写は狭い側へ、槍の軌道、跳躍、反撃は広い側へ渡す。3か所の主動作は実際の斜め表示辺でコマ間に傾きを作り、文字は正立を保つ。セリフは絵の空いた側にも置き、動作と選択の間を取る。ソースの3×2グリッドは素材管理のためで、完成プレビューではそのグリッドを縦へ積まない。
