# 『橋上の一歩』戦闘ネーム

[プレビュー](index.html) は戦闘一場面・24コマの部分試作。既存連載の一話ではなく、一話全体の分量判定は対象外。2026-10-09にコマ配置と動きを示すエフェクトの方向をユーザーが採用した。「そうそう！やっぱ戦いシーンは カッケー！！！って思わせないと」という評価を、今後の[動きと見せ場のエフェクト](../art-prompts.md#動きと見せ場のエフェクト)へ反映した。本作画と公開は未着手。

少年剣士アキが鐘楼へ向かう石橋で門番と対峙する。槍を避ける、剣を落とす、肩の予兆を読む、低い段差で剣を拾う、跳び越えて槍を弾く、通路が開くという因果を絵でつなぐ。前半はアキ右・門番左、剣は一本でp07に落下しp16に回収、p17以後は手にある。最後は目的地の鐘楼へ進む。

## 構成を確認する資料

- [plan.json](plan.json)：24コマ、声、間、表示窓、左右と高さの配置、縦書き全文
- [sequence-plan.json](sequence-plan.json)：コマごとの理解、意図、反応、位置、小道具の状態
- [storyboard.md](storyboard.md)：動き、無音、接続の判断
- [原画と実行した作画指示](art-provenance.json)：組み込みimage_genによる無文字の白黒ラフ4枚・各6カットと、攻撃・跳躍・反撃の専用原画3枚の対応
- [表示確認](validation.json)：360/390px幅の実測と目視範囲

生成PNGは無加工。HTMLの表示窓で24の独立した瞬間を見せる。足元、肩、指、仮面の接写は狭い側へ、槍の軌道、跳躍、反撃は広い側へ渡す。p05・p17・p20は斜めの枠を原画に描き、槍先、剣、頭、足、マント、飛ぶ石が枠の外へ突き抜ける。専用原画は全体を表示し、CSSの多角形マスクで身体を切らない。

跳躍は大きな遠近感で見せ、仮面の反応と着地は小さく左右へずらす。反撃の「ガキィンッ！」は白い枠外へ広がる一度の接触音とする。セリフは絵の空いた側にも置き、動作と選択の間を取る。ソースの3×2グリッドは素材管理のためで、プレビューではそのグリッドを縦へ積まない。

## 動きが読めるエフェクト

コマの位置と寸法、人物のポーズ、声と効果音の配置を保ち、主動作の原画をimage_genで部分編集する。エフェクトは発生源、進行方向、余波をつなぐ。

- p05：門番の左側から手前右の槍先へ大きな薙ぎ払いの帯を走らせ、足元の擦過線と砂塵でアキの後退を示す。まだ接触していないため火花は描かない。
- p17：低い右の段差に踏み切りの砂煙を置き、身体の後ろから左上へ続く軌跡と速度線で跳躍を示す。剣を振った斬撃にはしない。
- p20：アキの振り上げた剣の軌道を太い帯で示し、一つの接触点へ衝撃線を集める。右へ伸びる反発線で槍が弾かれた方向を示す。

大きな動線と衝撃を使いながら、顔、握り手、一本の武器の連続した輪郭を残す。人物や武器の複製を残像にせず、軌跡を抽象的な線や帯として描く。p21の無音へ入る前にエフェクトを終え、判断と余韻の空間を維持する。

## スマホ幅の実測

| 読書幅 | 本編高 | 内容の占有区間 | 純余白 | 有効コマ |
| --- | ---: | ---: | ---: | ---: |
| 390px | 9,585.719px | 7,273.934px | 2,311.785px | 24 |
| 360px | 8,848.313px | 6,716.866px | 2,131.447px | 24 |

余白は絵の表示窓、文字、効果音、外側の吹き出しの実際の縦占有を重ね合わせて一度だけ数える。声の白い要素全体を内容とは数えない。明示的なpauseだけを引いた値も別途残すが内容区間の確定値にはしない。原画内の大きな無情報帯は目視確認し、別途除外すべき帯はない。

セリフ実測は390px幅で21.06px、360px幅で19.44px。主動作の効果音は390px幅で46.8〜54.6px、360px幅で43.2〜50.4px。画像24/24が表示され、左右の文字欠け、横あふれ、ページ・コンソールエラーはゼロ。DPR3、幅変更、広い画面での390px制限、構成メモと計測の開閉も確認。これは単独HTMLをheadless ChromiumのsetContentで読む成果物確認で、ユーザーの既存ブラウザタブの操作や実機確認ではない。
