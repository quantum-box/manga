# 動作の音と装着過程

音をコマの外や大きな余白へ続けるときは[コマと余白を跨ぐ音](cross-panel-sounds.md)を読む。発生と持続を分け、次の静けさまでの残響を設計する。

「もっと効果音を使っていい」「装甲を装着する過程やシステムの仕組みを見せたい」といった改善で読む。既存の話の動作と設定を確認し、音や装着を見る楽しさを足す。全作品に変身やシステム画面を追加する指示ではない。

## 何が鳴るかを先に決める

効果音の数だけを増やさず、動作の原因、素材、重さ、速度に対応させる。音を付けるコマと位置、正確な語句、避ける顔・手・文字を指示へ書く。会話の吹き出しへ入れず、動作のそばへ画像と一緒に描き込む。

発話と音の有無は独立して決める。無言で歩くコマには足音を置ける。話しながら部品を固定するコマにはセリフと固定音を別々に置ける。返答を待つ表情のコマには両方を置かず静けさを残せる。生成指示の共通部分へ「無言コマは文字を一切描かない」と書くと、個別に指定した音も消えるため、発話・効果音それぞれの指示へ分ける。

| 原因 | 制作例 | 読ませ方 |
| --- | --- | --- |
| 手を伸ばす・触れる・握る | スッ、ぺた、ギュッ | 小さな接触を近くに置く。指と接触点を隠さない |
| 衣服が動く・落下する | バサァッ、ヒュウウッ | 布や落下の方向へ文字と動線を合わせる |
| 巨体が歩く・橋が壊れる | ズン… ズン…、バキバキッ！ | 重さと破断を区別し、発生源を追える位置へ置く |
| 部品が固定される・強く打つ | カチッ、ガシャッ、ガキンッ、ドゴォンッ！ | 小さな留め具から胸の固定へ強め、主打撃と破片の音も描き分ける |

字形、縁取り、色は作画に合わせる。強い音だけを連続させない。音を求められた範囲では接触や歩みも候補にし、判断、返答、安堵、最後の手掛かりに静けさを残す。すべてのコマを無音または有音へ揃えない。

## 完成形までの変化を楽しませる

装着の前後で、身体、衣服、手袋、足場、小道具がどの状態かを記録する。既存の完成形を参照し、部位のデザインや配色を勝手に変えない。必要な変化を接写で描く。

| 見せる段階 | 読者が理解すること |
| --- | --- |
| 起動と経路 | 何が力を出し、どこへ流れるか。まだ素肌や普通の衣服が見える |
| 部位ごとの形成・固定 | 部品の輪郭ができ、関節や装甲が閉じる。全身はまだ見せない |
| 動作と反応の確認 | 本人が拳や関節を動かし、装備が応える。必要な通知や残量だけを示す |
| 完成した姿 | 一拍置いて全身の決めゴマへ進み、その後の行動へ接続する |

この順序はヒーロー装甲の制作例であり、部位の順、段階数、コマ数は作品に合わせる。変身が一瞬で起きること自体に意味がある作品では、その演出を尊重する。速い固定動作は短くつなぎ、完成した姿の前に期待を置く。完成後の戦闘、将来のフォーム、敵の正体を途中の参照から漏らさない。

## 仕組みを作動と反応で伝える

説明の長文だけで埋めず、発生源から経路、動いた部位、結果を見せる。主人公にも小さな確認をさせ、理解と身体の動きをつなぐ。通知は絵で起きている段階を補助し、独立した設定の講義にしない。

有限の動力が既存設定にあるなら、残量の区画などを短く見せる選択がある。表示が示す内容と、まだ決めていない消費量、補充条件、制限時間、由来を区別する。数字やカウントダウンを演出だけの理由で新設しない。実際のアプリUIの開発とは分ける。表示の見え方は[システム表示](system-and-lettering.md)を参照する。

## 『ゼロブレイク』第1話の制作例

[装着過程3枚の一覧](zero-break/armor-sequence-390.png)を画像表示ツールで見る。各列は390px幅のネイティブ画像で、左から右へ順に読む。原画はブラウザで描画した画面ではない。この時点で360/390pxの画像確認と成果物のバイト照合を実施し、ブラウザと実機は未確認。内容の採用確認は画像の検証と区別する。

胸の核からシアンの光が流れ、素手の手首に格子ができる。黒い前腕・脚・胸を固定し、拳を動かして「……動かせる。」と確認する。「救済核残量」は六区画中四つが点灯し、「接続完了。」から既存の全身決めゴマへ進む。黒い装甲、シアンの星と継ぎ目、赤いマフラー、顔を覆わない条件を引き継いだ。区画数と点灯数はこの作品の例で、能力の普遍的な仕様ではない。

新たに3画像・7コマを挿入し、第1話は33画像・73コマになった。既存11画像の効果音編集と合わせ、効果音は17場面・計24語。画像数、コマ数、音のある場面数を混同しない。詳細な実行指示と編集元はmangaリポジトリの `examples/zero-break/production/episode-01-sfx/` に保存している。同梱の一覧は、その作業場所がなくても演出を確認できる見本。

## 改稿と確認

使える既存原画を保ち、効果音の部分編集と、新しい動作コマの挿入を区別する。画像生成の出力を無加工で採用し、元画像・修正前画像・実行指示・参照ハッシュを残す。今回、思考の点が拳を指したため、点だけを画面外の頭へ向けて修正した。手元の心の声も、手が話者に見えないように確認する。

小さいスマホ幅で音と通知の全文、手指、部品、残量区画、前後の状態を目視する。原画の拡大表示や全長を一画面に縮めた表示だけでは判定しない。装着の途中から全身、攻撃、安堵へ実際の幅で読み進める。

挿入順と音の編集を再構築でも保持し、単独リーダー、完成画像、話一覧のコマ数、脚本、アプリ同梱版を同じ採用版へ更新する。成果物の一致、ネイティブ画像、ブラウザ、実機、公開の状態を分けて記録する。
