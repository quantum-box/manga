## 各場面の役割

| 部分 | 読む速さと動き | 見せ方 |
| --- | --- | --- |
| バッグ→ポケット→空の手 | 短い動作を近くで読む | 大小三つのコマを下へずらす |
| 顔→雨だれ→地面 | 音の発生源を探す時間 | 一つの長い背景、音が先、猫はまだ出さない |
| 猫と鍵 | 発見に止まる | 枠のない大きな猫の顔 |
| 鍵を受け取る | 小さな交流で息をつく | 短い接写、鍵は手へ、猫の口は空 |
| 足跡→低い窓口 | 行き先をたどる時間 | 背景の縦の動線、問いを先に配置 |
| 帽子の猫と看板 | 正体と余韻 | 帽子はここで初めて登場。看板は後から正確に組版 |

一枚の長い背景にはカメラ移動のような省略・場面のつながりがある。写実的な単一透視図を機械的に要求するのではなく、上から下へ読むと視点や行き先が分かるかで判断する。

## 以前の版から変わった判断

横に広い絵をスマホに縮小すると顔や情報が小さくなった。正方形のコマを等間隔に並べ直しても、スクロール自体の意味が弱かった。この版は密な探索、長い見下ろし、発見、小さな交流、足跡、正体というリズムを先に決めた。

色、猫、雨、6枚という枚数はこの話の選択。新作ではテーマに合う動線や場面数を選ぶ。今回の正体の先出しを保護した距離は、あらゆる場面間に適用する余白の規則ではない。
