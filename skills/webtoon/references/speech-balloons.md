# 声と感情に合わせる吹き出し

吹き出しの設計と部分修正で使う。2026-10-06、ユーザーは写真を添えて「吹き出しいろんな種類のを使おう」と指摘した。写真には細い色付きの輪郭と、太く密なトゲ状の輪郭があり、線の太さ・色・形でも声の違いを表す方向を示していた。

種類を並べることを目標にせず、その言葉が声に出ているか、誰へ届くか、強さや呼吸はどうかから選ぶ。採用済みのコマ割りと会話の間を保ったまま、発話ごとの見え方を直す。写真の文字・人物・コマ配置を新作へコピーする必要はない。

## 選ぶ基準

| 発話の役割 | 輪郭と線の選択例 | 尾・注意点 |
| --- | --- | --- |
| 普通の声 | 滑らかな楕円、簡潔な細い線 | 尾を口の方向へ。会話の基本形として一貫させる |
| 落ち着いた名乗り・説明 | 角を丸めた縦長の形、整った輪郭 | 作中の通知やナレーションの箱と混同しないよう、話者へ尾を付ける |
| 柔らかい声・弱い息 | 緩やかな曲線、少し揺れる輪郭、控えめな線 | 口へつながる細い尾。雲形と点だけにして心の声へ変えない |
| 叫び・強い呼びかけ | トゲ、放射状の線、太い縁の強弱 | 鋭い尾で話者を示す。怒り・驚き・切迫は表情と文脈で分ける |
| 心の声 | 雲形と小さな点、または作品で決めた独白の表現 | 点は考える人へ。通常の発話の尾で口へつなげない |

形、色、太さを毎回全て変えない。同じ人物の基本の声はそろえ、感情や強さが変わる箇所で変える。色を使う場合も、色だけに意味を持たせず、輪郭や尾で違いが分かるようにする。沈黙の反応コマへ、新しい吹き出しを足す必要はない。

疑問符や感嘆符は、自然な問い、驚き、制止、強い呼びかけや語気を持つ発話の一部として使ってよい。全話で記号を無くす統一や、毎文へ付ける強制はしない。記号だけで感情を処理せず、吹き出しの輪郭と尾、表情、聞き手の反応、間を合わせて確認する。

## 実例：採用した8コマの吹き出しを変える

**状態：吹き出しの追加改稿は作画済みの試作。ユーザー評価は未確認。** コマの大小と枠を使う版は採用済みだが、その評価をこの追加改稿へ自動で広げない。

[比較リーダー](zero-break/index.html)の「吹き出しを使い分けた8コマ」で読む。[前半](zero-break/balloons-01.png)と[後半](zero-break/balloons-02.png)も表示する。セリフと8コマの順序は同じで、元の[前半](zero-break/varied-01.png)・[後半](zero-break/varied-02.png)を保存している。

| 発話 | 今回の選択 | 伝えたい声 |
| --- | --- | --- |
| ミラ「ありがとう。」 | 柔らかく少し不均一な輪郭、青灰色の細い線 | 助かった直後の温かな礼 |
| ミラ「私はミラ。」「この国の王女よ。」 | 角を丸めた縦長の形、同じ系統の線色 | 落ち着いた自己紹介 |
| レン「レンだ。」 | 普通の楕円と簡潔な尾 | 飾らない返答 |
| レン「無事なら、それで。」 | 少し揺れる輪郭と細い尾 | 救出後の疲れと安堵が混じる声 |

静かな会話なので、叫びのトゲや心の声の点は混ぜない。顔、手、左右の関係、無言の目元、コマの大小、最後の枠なしの画面を保つことを編集の条件にした。[前半の編集指示](zero-break/prompt-balloons-01.txt)と[後半の編集指示](zero-break/prompt-balloons-02.txt)に、各発話の声と輪郭を残す。

## 実例：叫びと心の声

「叫びと心の声」の比較は、会話8コマとは別の場面の演出例として読む。場面を入れ替えた一話の漫画として扱わない。

- [救出中の叫び](zero-break/balloon-shout.png)：レンが落下するミラを抱きとめて「つかまって！」と呼ぶ。細いトゲだった[原画](zero-break/balloon-shout-before.png)を、写真の輪郭を参考に太く密なトゲ状の縁へ編集した。文字の内側余白と、レンへ向ける鋭い尾を保つ。[編集指示](zero-break/prompt-balloon-shout.txt)。
- [測定後の心の声](zero-break/balloon-thought.png)：魔力ゼロと告げられたレンが、自分の素手を見て「……ここでも、何もできないのか。」と考える。既存の採用原画を保持した例で、雲形から頭へ小さな点が続き、相手へ話した声と区別できる。

[生成の出所](zero-break/generation.json)には、編集した3枚と保持した原画の違い、参照の役割、採用状態を残す。写真は輪郭の参照であり、スキル同梱の作画は『ゼロブレイク』のものを使う。

## 確認すること

1. 発話・叫び・心の声が、文脈、輪郭、尾から分かる。
2. 尾や点が正しい人へ向き、画面外の声を物の発話に見せない。
3. 太い線やトゲでも内側余白を保ち、文字・顔・手を覆わない。
4. 同じ人物の基本の声がそろい、形の変化が声や感情の変化と合う。
5. 狭いコマでも全文・縦列の順を読め、吹き出しの大小が採用したコマの強弱を壊さない。

画像の読み込み、輪郭の目視、スマホ幅の文字確認、ユーザーの評価を[確認記録](zero-break/validation.json)で分ける。指示どおりの形にならなければ、該当する吹き出しだけを再編集する。使えるコマ割りや表情まで作り直さない。
