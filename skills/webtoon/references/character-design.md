# キャラクターの設計

新しい人物を作るとき、長期の人物像や関係を設計するとき、人物の行動・外見がぶれるときに読む。設定は `series/characters.md` に保存し、採用した参照画像へのリンクを付ける。人物ごとに安定した識別子を使い、名前や呼び方の違いで別人を作らない。

## 行動の理由を設計する

主人公・主要な相手・敵・物語を動かす脇役について、次を決める。全員へ同じ傷や成長の型を当てはめない。

| 項目 | 物語で確認すること |
| --- | --- |
| 欲しいものと理由 | 何を得たい・守りたい・避けたいか。それが今の行動につながるか |
| 価値観・恐れ・矛盾 | 何を優先し、何を認めたくないか。圧力の中でどんな選択をするか |
| 能力と制約 | できること、知っていること、感情として受け入れられることを区別する |
| 関係 | 相手から何を求め、何を隠し、どんな誤解・信頼・力の差があるか |
| 話し方と演技 | 語彙、敬語、文の長さ、沈黙、姿勢、反応に人物固有の違いがあるか |

「勇敢」「優しい」などの形容だけで終わらず、それが見える行動と、同じ性質が問題を起こす場面を考える。敵は主人公の成長を待つだけの存在にせず、自分の目標、進め方、守るもの、踏み越える線を持たせる。

各場面では、なぜその人物が今その行動を選ぶのかを問う。「欲しいもの／必要なもの」を区別する手法は使える場合に使い、全員への必須の型にしない。主人公の知識、身体の能力、感情を別に扱う具体的な演出は [感情と行動の因果](emotion-and-causality.md) を参照する。

## 人物と関係の長期変化

全体の目標話数に合わせ、初登場、導入10話の到達点、主要アークの転換、長期の終着点を描く。外的な目標と、信頼・自己認識・価値観などの内的な変化を結び付ける。安定した人物像が作品の面白さになる場合は、その人物が周囲や関係へ与える変化を設計する。

成長や接近は出来事の結果として積み上げる。長期話数のために毎回同じ失敗や誤解へ戻さず、克服済みの問題、まだ残る弱点、前の選択の代償を区別する。主人公以外にも決断と結果を与え、全員の問題を初回10話で解決し切らない。

関係は双方向で考える。AがBへ求めるものとBがAへ求めるものが違う場合、その差が会話・協力・対立をどう生むかを記録する。主要な組み合わせの関係は、各話の出来事で何が変わったかを状態台帳へ残す。

## 再現できる見た目を作る

主要人物には、体格・身長差・顔・髪・配色・輪郭で識別できるキャラクターシートを作る。正面・横・斜め、よく使う表情、全身の衣装、小道具の形を必要に応じてまとめる。デザイン段階で同じ顔の人物が増えていないか、スマホ幅で見分けられるかを確認する。

物語上の役割が薄い複雑な装飾を増やしすぎない。服装・道具・身体の特徴は暮らし、職業、文化、人物像とつなげる。作画には共通の参照画像と不変条件を渡し、衣装の別版には識別子と使う時期を付ける。

| 不変条件として扱うもの | 場面ごとに変わる状態 |
| --- | --- |
| 基本の体格、顔、髪・瞳の色、特徴の位置 | 表情、姿勢、汚れ、負傷、疲労 |
| 衣装ごとの形、配色、道具の基準形 | 衣装の採用版、破損、持ち物、持ち手 |
| 既に確立した性格・口調・能力のルール | 知識、感情、関係、目標、成長段階 |

意図した変化は理由と初出の話を記録し、作画の揺れと区別する。後の成長した姿や正体を、前の話の参照画像から漏らさない。

## 設計の確認

主要人物の見た目・話し方・選択が区別できるか、欲望と恐れから行動が生まれるか、世界でその立場になった理由があるかを確認する。長期の変化がロードマップと一致し、現在の知識・関係・持ち物が次の話へ引き継げるようにする。

参考： [Tapas公式の人物シート](https://www.creators.tapas.io/before-publishing)、[Webtoon作家によるデザイン解説](https://www.clipstudio.net/how-to-draw/archives/166899)、[John Augustの人物の動機について](https://johnaugust.com/2008/rethinking-motivation)。基本設定・表情・衣装の参照と、行動の理由を結び付けるための判断材料として使う。
