# 第1〜10話の導入アーク

新規シリーズの初回制作、または導入の構成を見直すときに読む。シリーズの規模、世界観、主要人物、長期ロードマップを確認してから `series/opening-arc.md` に最初の10話を設計する。全体が10話未満の指定なら、その話数に合わせる。

## 長い物語の面白さを最初から体験させる

長期連載でも、導入だけで主人公の問題と作品固有の面白さを体験できるようにする。説明や準備だけを長く続けず、世界のルールが主人公へ作用し、本人の選択が結果を生む出来事を置く。

[WEBTOON Creators 101](https://us.webtoons.com/en/creators101/webtoon-canvas) は3話以内に主要な対立を示すことを推奨する。これは全設定の説明や全ての敵の登場を3話までに済ませる指示ではない。読者が誰の何を応援する物語か分かるかを確かめる。

次は冒険・成長ものなどで使える配分例。各話の役割や山場の位置を全作品へ固定せず、恋愛・日常・ミステリーでは関係や情報の変化として読み替える。

| 範囲 | 役割の例 | 読者へ渡すもの |
| --- | --- | --- |
| 1話 | 主人公への関心、世界の圧力、選択、出来事の始まり | この作品で得られる面白さ |
| 2〜3話 | 目的と主要な対立、次へ踏み出す選択 | 応援する理由と具体的な期待 |
| 4〜7話 | 試行・結果・失敗・協力・関係の変化 | 小さな成果と、深まる課題 |
| 8〜10話 | 局地的な山場と決着、変化した状況 | 導入を読んだ満足と次のアークへの期待 |

導入の問題は10話までに何かを解決する。200話以上の主な対立には余地を残し、局地的な決着が大きな問いや次の目的へつながるようにする。初回10話に全キャスト・全地域・全能力を登場させる必要はない。

## 各話の設計カード

第1〜10話を通して次の項目を埋め、前の話の結果が次の話へつながるかを読んで確認する。

各話の分量は[一話の長さと読み応え](episode-length.md)で設計する。通常話の8〜12分という目標、予定の有効コマ数、十分に読む主筋のまとまりもカードへ残す。出来事の要約や短い引きだけを、一話の完成分量として割り当てない。

1. **開始と終了の変化**：出来事、知識、感情、関係のうち何が変わるか。
2. **因果**：人物の目的 → 障害 → 選択 → 行動 → 結果。反応と理解に必要な場面も入れる。
3. **その話の満足**：成功、発見、関係の前進、笑い、余韻など、今回読んで得られるもの。
4. **情報の開示**：見せる世界のルール、伏線の提示・回収、まだ見せない真相。台帳の識別子とつなぐ。
5. **次へ読む理由**：選択の結果、新しい疑問、関係の変化、次の目標など、その話から自然に生まれる期待。

毎回同じ危機の直前で切らず、驚き・期待・感情・静かな約束など終わり方を使い分ける。冒頭では前話の引きに応え、都合よく出来事を無かったことにしない。大事件の後は、人物が結果を受け止める場面も設計する。

## 脚本から縦の絵コンテへ

10話分の各話カードと脚本を先に作り、導入全体の因果・人物の成長・世界の説明量を見直す。各話の `storyboard.md` には正確なセリフ、話者、見せる／伏せる情報、身体と小道具の状態、密度と間を記録する。場面の数、コマ数、生成画像の枚数は別に扱う。

文字、表情、動作の理由が伝わるかを縦のラフで確認する。読み進めるために必要な理解まで隠したり、話数に合わせるためだけに小さな動作を反復したりしない。スクロールの距離だけで不足した因果を補わない。詳しい演出は [感情と行動の因果](emotion-and-causality.md) と [間とスクロール](scroll-pacing.md) に従う。

## 作画へ進む前の確認

最初の3話で目的と対立が伝わり、各話に変化と満足があり、10話に局地的な到達点があるかを確認する。世界観の説明が行動と結び付き、人物が現在の知識で選択し、長期の秘密が先に漏れていないかを照合する。ネームの実量と読了時間の計測状態を計画と比較し、短すぎる回や水増しした回は本作画前に脚本・台帳を直す。長期の話数を埋めるために、十分な一話を短く分割しない。

参考： [Webtoon作家の制作手順](https://www.clipstudio.net/oekaki/archives/174136) は章の転換点からエピソードへ分割し、重要な出来事の後に展開を落ち着かせる回も置く。この資料とWEBTOON公式の導入指針を、初回10話というユーザーの制作単位へ応用している。
